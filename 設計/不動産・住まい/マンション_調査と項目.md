# SeiZen｜不動産・住まい　マンション　調査と項目

作成 2026-09-29。種別が「マンション」の物件で、今のうち・そのとき・下の部屋に
何を載せるかを決める。判定の基準は `今のうち-そのとき_調査と項目.md` §3-5
（今のうち＝本人が失われると取り返しがつかないか／そのとき＝知らないと
組み立てられないか）と、`下エリア_調査と項目.md` §5-0 の2段階（①振る舞いが
変わるか → ②記録か知識か）。

前提（前セッションで決定・覆さない）：境界・越境／私道・通行・配管／建物の
変更・登記の3件は、マンションでは問いが立たないので**出さない**（「該当なし」
の札も出さない）。

## 1. 調べたこと

### 1-1. マンションの居住と管理の現状 ―― 国交省 令和5年度マンション総合調査

管理組合向け N＝1,589、区分所有者向け N＝3,102。

| 事実 | 数字 |
|---|---|
| 世帯主が70歳以上 | 全体 **約3割**。昭和59年以前に完成したマンションでは **55.9%** |
| 永住するつもり | 60.4% |
| 管理費・修繕積立金の3か月以上の滞納がある管理組合 | 滞納なし 62.1%（＝**約4割に滞納住戸がある**）。古いほど多い（昭和59年以前 43.2%） |
| 所在不明・連絡先不通の住戸がある管理組合 | 3.3%（古いほど多い） |
| 外部専門家を選任した理由「管理費の滞納等への法的措置」 | 30.5%（N＝658） |
| 管理組合が抱えるトラブル | 居住者間のマナー 60.5%（生活音 43.6%・違法駐車 18.2%・ペット 14.2%）／建物の不具合 31.7%（水漏れ 20.1%・雨漏り 10.7%）／費用負担 24.2% |
| 使用細則を定めている事項 | 駐車場 81.8%／専有部分の使用・居住 81.1%／専有部分の修繕等 71.4%／ペット 70.5% |
| 老朽化対策で「建替え・解体」の方向で具体的に検討した | 0.1〜0.3%（修繕・改修の方向は 11.3%） |

→ マンションでは、戸建てで「隣との取り決め」「建物の変更」だった事柄が、
**管理組合という組織と、その規約・細則・記録**に置き換わっている。

### 1-2. 管理費・修繕積立金は、誰が払うか ―― 区分所有法・判例

| 事実 | 出どころ |
|---|---|
| 管理組合は、滞納した区分所有者の**特定承継人（買主など）にも**請求できる（区分所有法8条）。売買契約で「引き継がない」と決めても管理組合は拘束されず、買主が知らなくても負う | 区分所有法8条／retpc https://www.retpc.jp/archives/21898/ ／羅針盤 https://law-rashimban.com/shokeinin/ |
| 相続人は8条ではなく**相続（包括承継）で**、亡くなる前の滞納を引き継ぐ。**法定相続分に応じた分割債務** | 羅針盤 https://law-rashimban.com/shoyushasibo/ ／マンション弁護 https://mansionbengo.jp/kanrihi-syuuzentsumitatekin/shibou |
| **亡くなった後に発生する管理費等は、相続人それぞれが全額を払う義務**（性質上の不可分債務：東京地判平18.7.21、東京高判平20.5.28）。遺産分割がまとまるまで「誰が払うか決まっていない」ではない | 同上／retpc |
| 管理組合は滞納について、区分所有権と建物に備え付けた動産に**先取特権**を持つ（区分所有法7条）。相続人に請求し、応じなければ訴訟・**競売**まで進んだ事例がある | 区分所有法7条／国交省 事業成果「相続人不在・相続放棄となった住戸における管理組合としての対応」（9事例）https://www.mlit.go.jp/jutakukentiku/house/content/001352624.pdf |
| 同事例集：死亡後に**相続登記がされず滞納が続く**、相続人調査・訴訟・競売・相続財産管理人。滞納の時効は5年 | 同上 |
| 専有部分が共有になると、**議決権を行使する人を1人**定めなければならない（区分所有法40条） | 区分所有法40条 |
| 組合員の資格を取得・喪失した人は、**管理組合に届け出る**（標準管理規約31条。令和7年改正で届出事項の変更も届出）。総会の通知は届け出たあて先に送られ、届出がなければ部屋の住所へ送られる（同43条） | 国交省「令和7年マンション標準管理規約改正」https://www.mlit.go.jp/jutakukentiku/house/content/001968331.pdf ／Wikibooks 標準管理規約31条 |

★**「引き落とし口座」は落としたまま**（銀行口座カテゴリが持つ）。ここで
拾うのは口座ではなく、**死亡後の管理費が不可分債務であること**と、
**亡くなる前の滞納が相続債務になること**という別の事実。

### 1-3. 専有部分のリフォームと管理組合の承認 ―― 標準管理規約

| 事実 | 出どころ |
|---|---|
| 専有部分の修繕・模様替え・取替えは、**あらかじめ理事長に申請し書面の承認**を受ける（設計図・仕様書・工程表を添付）（標準管理規約17条）。床材（遮音）・配管の枝管・ユニットバス・間取り変更が典型 | 横浜マンション管理・FP研究室 https://yokohama-mankan.com/management-regulations-article-17/ |
| 17条コメント：管理組合等が**専有部分の修繕の記録を保管**しておくため、工事完了報告書等を提出させる | 同上 |
| 承認のない工事には、理事長が勧告・指示・警告、差止め・原状回復の措置を取れる（同67条） | 同上 |
| 分譲時の設計図書（平面図・立面図・構造図・仕様書など11種）は、分譲会社から**管理組合へ交付**される（マンション管理適正化法103条）。管理組合は修繕履歴とともに保管し、区分所有者の求めで閲覧させる | R.E.port https://www.re-port.net/article/news/0000050402/ ／適正化法103条 |

→ 承認を得た工事は**管理組合に記録が残る**。建物の図面も管理組合にある。

### 1-4. 駐車場の使用権 ―― 標準管理規約15条

| 事実 | 出どころ |
|---|---|
| 駐車場は管理組合との使用契約（賃貸方式が主流、債権的な使用権） | 木浦学 https://note.com/condoma/n/nbe584ba079ea ／マンション管理士がゆく |
| 標準管理規約15条3項：専有部分を**譲渡・貸与したら**使用契約は効力を失う。**相続は書いていない** ―― 続けられるかは各マンションの使用細則次第 | 同上 |

### 1-5. 定期借地権付きマンション

地代と解体準備金を毎月払い、期間満了で更地にして返す。売るときは地主への
通知・承諾が要る型がある。相続は承諾不要（借地と同じ）。
https://president.jp/articles/-/69362 ／ https://www.clo.jp/wp-content/uploads/2024/05/Fixed-term_leasehold_apartment.pdf

→ 権利関係の「借地」はマンションにもありうる。今の選択肢（所有／共有／
借地／その他）のままで受けられる。供給が少ないので、今回は形を作らない。

## 2. 判定

### 2-1. 今のうち ―― マンション固有のものは立たない

仮説3つと、調べる中で出た候補を §3-5 と2段階で当てた。

| 候補 | 判定 | 理由 |
|---|---|---|
| 管理費・修繕積立金の滞納が引き継がれる | **今のうちではない → そのときへ** | 事実は正しい（§1-2）。ただ滞納額は**管理組合の記録**で、家族が管理会社に照会すれば分かる。父の手でしかできないことも、父しか知らないことも無い。効くのは死亡後（相続放棄の判断・支払いの段取り）なので、そのときの材料 |
| 専有部分のリフォームを、管理組合の承認を得て行ったか | **落とす**（第1段階） | 承認した工事は管理組合が記録を持つ（§1-3）。承認のない工事は、下の階からの苦情として父が住んでいる間に管理組合を通じて表に出る。残るのは売るときの告知書（物件状況等報告書）の話で、これは雨漏り・設備の故障と同じ「売主が知っている建物の状態」の一般の問題。戸建てでも SeiZen は告知書の項目を持っていない（持つと片付け・点検の一覧になる）。相続で取得した物件は「相続のため不明」で売るのが通例で、書いても家族の振る舞いが変わらない |
| 駐車場の使用権を、相続で引き継げるか | **今のうちではない → そのときのくわしくへ** | 決めるのは使用細則で、管理会社に聞けば分かる（§1-4）。父の手・父の記憶は要らない |
| 総会の議決権（建替え・再生の決議） | **落とす**（重さと遭遇率） | 判断力が落ちると父は議決権を使えないが、建替え・解体の方向で具体的に検討した管理組合は 0.1〜0.3%（§1-1）。令和7年改正で特別決議は出席者の多数決になり、欠席が反対に数えられる場面も減った |
| 管理組合への緊急連絡先・代理人の届出 | **落とす**（第1段階） | 家族が管理会社へ伝えればよい。父でなければできないことではない |
| 漏水事故の履歴・示談 | **落とす** | 管理会社が調整に入るのが通例で、示談書が残る。告知書の一般の問題（上と同じ） |
| 理事長・会計として預かっている管理組合の通帳・印鑑 | **落とす** | 管理組合が知っていて、返してほしいと言ってくる。家族が組み立てられないことではない |

**結論：マンションで「本人しか知らない」ものは、管理組合の記録に吸われる。**
戸建ての今のうち3件は、どれも「登記にも書類にも出ない、父と相手だけが
知っている事実」だった。マンションでは相手が隣ではなく管理組合で、
管理組合は規約・承認・議事録・名簿・滞納額・設計図書を記録として持つ。
だから今のうちには、**戸建てと共通の2件だけ**が残る。

| 立つ条件 | 項目 | マンションでの文 |
|---|---|---|
| 常に | 前の代の相続登記 | 問いは「専有部分の登記に、前の代の名義が残っていますか」。どれが前の代の名義かは聞かない（専有部分1つ） |
| 借入があり、団信が分からない | 団信の加入状況 | 戸建てと同じ |

★**今のうちが1行になるのは誤りではない。** 父が自分で買ったマンションなら、
前の代の相続登記はふつう「残っていない」＝該当なし。立った項目は消さない
（§3-3）ので、行は「該当なし」で残る。空欄と該当なしは別（§11）。
**マンションは今のうちに父から聞いておくことが戸建てより少ない、**という事実を
そのまま映す。説明文は足さない（共通の言葉は言い直さない）。

### 2-2. そのとき ―― 「管理組合」の1枚を足す

戸建てと共通のカード（現所有者の申告／相続登記／ローン／貸している／借地）は
マンションでもそのまま成り立つ。文だけ確かめた：

- 相続登記：対象の名前は「専有部分」（実装済み）。敷地権は建物と一体で移る
  ので、家族が土地を別に意識する場面は無い（下エリア §5-1、蒸し返さない）
- 現所有者の申告：専有部分と敷地の持分のどちらも固定資産税がかかり、手続きは同じ
- 相続登記の「登記と今の建物のずれ」「前の私道の持分」はマンションでは立たない
  （元になる今のうちの行が無いので、自然に出ない）

**足すもの：管理組合（管理費・修繕積立金と届出）** ―― 立つ条件：マンションで、父の分がある

§3-5「知らないと組み立てられないか」を通る理由：

1. **分割がまとまるまで待ってはいけない。** 死亡後の管理費等は相続人それぞれが
   全額を負う（不可分債務）。父の口座からの引き落としは止まり、滞納になる。
   滞納は遅延損害金がつき、管理組合は先取特権で競売まで進める（§1-2）。
   「まだ誰が継ぐか決まっていないから」と置くと詰まる
2. **亡くなる前の滞納は、相続放棄の判断材料。** 相続債務（法定相続分）なので、
   3か月の判断の前に管理会社へ額を確かめる
3. **組合員の届出と、議決権を使う人。** 継いだ人が届け出る。共有にするなら
   1人を決めて届ける（区分所有法40条）

★以前落とした「管理委託の引継ぎ」（契約者が変わるのは家族も分かる。続けるかは
判断）とは別物。管理組合は**やめられない**（区分所有者は当然に構成員：
区分所有法3条）。続けるかの判断ではなく、払い方と届出の段取り。

カードの中身：

| 段 | 中身 |
|---|---|
| 一文 | 亡くなった月からの管理費・修繕積立金は、遺産分割がまとまるまで、**相続人それぞれが全額を払う義務**を負います。 |
| 相手 | 契約の「管理」に記録した管理会社（無ければ「管理組合（管理会社）」） |
| すること | すぐ：管理会社へ知らせ、分割までの払い方と、連絡を受ける相続人を決める／3か月以内：亡くなる前の滞納がないか確かめる（相続放棄を考えるときの材料）／分割のあと：継いだ人が組合員の届出をする（共有なら議決権を使う1人も） |
| くわしく | 払わないと（遅延損害金・先取特権・競売）／亡くなる前の滞納（法定相続分・放棄）／駐車場（相続で続けられるかは使用細則次第。管理会社に確かめる）／売るとき（滞納は買主にも請求されるので、決済で精算する：区分所有法8条） |
| 並び | 期限の早い順で先頭（毎月発生するため） |

### 2-3. 下の部屋

| 部屋 | マンションでの形 | 根拠 |
|---|---|---|

## 5. 見直し（2026-09-30）―― §2 の項目と見出しを改めた

§2 は戸建ての画面の部屋割りを前提に項目を並べていた（「貸している」「続いている相手」
「管理組合の月額」など）。0ベースで、マンションで家族が通る場面から組み直した。

### 5-1. 追加で調べたこと

| 事実 | 出どころ |
|---|---|

### 5-2. 判定の変更

- **ローンは「あれば」ではない。** 借りて買うのが多数派で、父の年代では返し終えているのが普通。
  中心は返済中の団信より、**返し終えて抵当権が抹消されているか**
- **「貸している」（家賃収入）は外す。** 収益物件は種別「その他」（`KINDS` の注記）。住まいのマンションの項目ではない
- **管理組合の月額は持たない**（§13-1 継続更新：段階増額方式 47.1%）。窓口の管理会社も現地・引き落とし明細で分かるので
  記録にしない（そのときのカードに探し方を書く）。**管理組合は材料の部屋にならない**
- **利用状況**は 両親／父だけ／母だけ／家族（◯人）／空いている の事実で持つ（年代で推さない）。
  母・同居家族・無償で住む家族には、そのときに家族がすることが無い（自動で成立、または本人の希望の範囲）ので項目にしない。
  **父が住んでいないときは、登記の住所がずれている手がかり**になる
- **登記の住所（今のうち）を足す。** 父が申請するか申出をしないと直らず、判断できなくなるとできない。亡くなった後は
  相続登記で住所のつながりを示せば足りる。マンション固有ではない（今回はマンションで扱う）
- **書類のありか**は 権利証／買ったときの売買契約書・重要事項説明書／リフォームの工事契約書・領収書／
  抵当権の抹消書類（返し終えて抹消していないとき）。管理規約・設計図書は管理組合にある
