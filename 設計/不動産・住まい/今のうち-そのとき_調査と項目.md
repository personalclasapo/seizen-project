# SeiZen｜不動産・住まい　「今のうち」「そのとき」　調査と項目

作成 2026-09-19。項目設計 §0 の「中央＝家族が実際にすること」のうち、
**今のうちに確認しておくこと**／**そのとき使うもの** に何を入れるかを決める。

起点は**本人の状態**。不動産はそこに現れる対象の一つであって、
物件の種別から入らない。

---

## 1. 調べたこと

前回は専門家の解説記事から論点を拾って失敗した。今回は
**n数のある調査と公的統計**を起点にし、解説記事は数値の裏づけにだけ使う。

### 1-1. 「そのとき」は死亡ではない ―― 国交省 令和6年空き家所有者実態調査

対象13,268世帯／回収6,294世帯（回収率約51%）、令和6年11〜12月。
令和7年8月公表。

**人が住まなくなった理由**（N＝1,170千戸）

| 理由 | 割合 |
|---|---|
| 死亡 | 43.9% |
| 別の住宅に転居 | 39.0% |
| 老人ホームなどの施設に入居 | 10.0% |
| 転勤など（一時的不在） | 3.7% |
| 入院など（一時的不在） | 1.2% |

**家が空くきっかけの過半（転居39.0＋施設入居10.0＋入院1.2＝50.2%）は、
本人が生きている間に起きている。** 相続で取得した空き家に限っても
死亡は58.3%で、残り約4割は生前に空いている。

→ 「そのとき」＝死亡、という置き方は事実に反する。
**本人が住まなくなる**という段階が、死亡とは別に立っている。

### 1-2. 生前の対策は、ほぼされていない ―― 同調査

**相続前の対策状況**（N＝742千世帯）

| | 割合 |
|---|---|
| 相続前に対策を講じていない | 77.0% |
| 相続前に対策を講じた | 23.0% |

対策の内訳（複数回答）

| 対策 | 割合 |
|---|---|
| 被相続人との話し合い | 16.7% |
| その他の対策 | 4.3% |
| 遺言の作成支援 | 1.8% |
| 後見制度や家族信託の活用 | **1.3%** |

そして**対策の有無で結果が変わっている**。対策無しの空き家は、
何もせずそのまま空き家として所有され続ける割合が**約1.5倍**
（対策無し45.1% / 対策有り29.4%）。

→ **実際にされている生前対策は「話し合い」だけ**。制度（信託・後見・遺言）は
合わせて3%台で、事実上使われていない。これは最高裁の統計とも一致する
（§1-5）。SeiZen が「今のうち」に置くべきは**制度の手続きではなく、
話し合いの中身**である。

### 1-3. 共有だと登記が止まる ―― 同調査

**登記または名義変更の有無**（N＝1,256千世帯、令和5年10月1日時点＝相続登記義務化前）

| 所有者の数 | いずれも行っていない |
|---|---|
| 1人（単独所有） | 12.5% |
| **2人以上（共有）** | **23.8%** |

空き家の種類別でも、使用目的のない空き家は17.6%と高い。

→ 共有は「揉める論点」として語られがちだが、数字に出ているのは
**手続きが止まる**という形。単独所有の約2倍。

### 1-4. 一方で、認知症・共有の「合意できない」は上位に出ない ―― 同調査

空き家として所有しておく理由（N＝323千世帯、複数回答）の下位：

| 理由 | 割合 |
|---|---|
| 所有者が複数で合意が困難 | 2.2% |
| **関係者が認知症などで意思決定できない** | **0.6%** |

上位は「物置として必要 55.8%」「解体費用をかけたくない 47.3%」
「住宅の古さ 37.0%」。

→ **重さと遭遇率を混同しない**（前回の反省）。認知症による凍結は
起きたときは深刻だが、空き家が放置される理由としては最下位に近い。
**「今のうち」を認知症対策の画面にしてはいけない。**

### 1-5. 本人の手でしかできない手続き ―― 最高裁 成年後見関係事件の概況（令和6年）

終局事件41,620件。**主な申立ての動機**（複数回答、母数＝終局事件総数）

| 動機 | 件数 | 割合 |
|---|---|---|
| 預貯金等の管理・解約 | 38,561 | 92.7% |
| 身上保護 | 30,599 | 73.5% |
| 介護保険契約 | 18,623 | 44.7% |
| **不動産の処分** | **14,990** | **36.0%** |
| 相続手続 | 10,855 | 26.1% |
| 保険金受取 | 7,132 | 17.1% |

そして利用者数（令和6年12月末）は総数253,941人のうち、
**任意後見はわずか2,795人**。

→ 前セッションが見つけた「**本人の手でしかできない手続き**」という型は、
n=1の体験記ではなく**国の統計で裏づく**。家庭裁判所に行く動機の
36.0%が不動産の処分であり、その時点で本人はもう自分で動けない。
かつ、事前に備える制度（任意後見）は全国で2,795人＝ほぼ使われていない。

**この型は項目設計に入れる。** ただし入れ方は「信託を契約しましたか」ではない
（§1-2・§1-4より、それは該当なしばかりになる）。

### 1-6. 家族は書類の在り処を知らない ―― すむたす 実家じまい意識調査

2025年11月20日〜12月6日、親世代60〜89歳 有効回答102名／
子世代30〜59歳 有効回答110名。**n が小さいので方向性としてのみ扱う。**

- 親子で実家について**話し合ったことがある 32.5%**（約7割が話し合いなし）
- 子世代の**76.4%が権利証などの保管場所を「把握していない」**
- 子が親に求めること：不用品整理 43.6% ／ **重要書類の整理 33.6%**
- 一方**親世代の76.5%が「協力してほしいことは特にない」**
- 話し合わない理由：親 63.1% ／ 子 43.6% が「まだ具体的に考えていない」

「約7割が話し合っていない」は、n=2,346 の三菱地所の調査
（2021年9月、40〜60歳代中心）の「**両親と相続について話したことがない 約70%**」
と一致する。桁の違う2調査で同じ数字が出ているので、この点は信頼できる。

→ **非対称が本体**。親は「渡すものは特にない」と思っており、
子は「書類がどこにあるか分からない」と思っている。
SeiZen が §9 で「問いは SeiZen 側が持つ」としているのは、まさにこの型に効く。

### 1-7. 詰まるのは名義変更 ―― 複数調査で一致

| 出どころ | n | 数字 |
|---|---|---|
| 日本トレンドリサーチ／ニーズ・プラス 2023年12月 | 1,000 | 不動産相続で大変だったことがある 54.6%／その1位 **名義変更 36.7%**／2位 親族間のすり合わせ 22.7%／**事前にやっておくべきことがあった 62.0%** |
| いい相続／鎌倉新書 2023（既出） | 400 | 専門家に任せた手続き：**不動産の名義変更（相続登記）64.2%**／戸籍収集 60.4% |
| 相続弁護士相談広場 2021（既出） | 226 | 困ったこと：何から手をつけたらよいか分からない 41.7% |

→ 名義変更は「1位で詰まる」かつ「6割強が自分でやらず専門家に投げる」。
**つまり SeiZen が手順を教える対象ではない。** 家族は専門家に頼む。
専門家に頼むときに必要なのは、**どの不動産が・誰の名義で・書類はどこか**
という材料である。SeiZen が持つべきはそこ。

### 1-8. 決まっていない ―― イエコン 2024年7月（n=1,000）

実家が戸建てで将来空き家になる予定／相続しそうな男女1,000人。

- 実家が空き家になった後どうするか：**「まだ決めていない」52.9%**
  （売却して現金化 16.4%／自分や親族が住む 11.7%）
- 相続したくない 53.2%／相続したい 46.8%
- 実家をなくすことに抵抗がある 55.2%

→ 過半が決めていない。**SeiZen は「結論を書かせる欄」を作ってはいけない。**
決まっていないことが普通の状態であり、それは §11 の状態として持つべきもの。

### 1-9. 制度が変わった ―― 所有不動産記録証明制度（2026年2月2日施行）

登記名義人本人・その相続人等が、**全国どの法務局でも、人を基準に
その人名義の不動産を一覧で取れる**ようになった。手数料1,600円（書面請求）。

ただし限界がある（★当初「漏れる」と書いていたが強すぎた。訂正済み）：

- 検索は「氏名の前方一致＋住所の市区町村一致」等で行われる。
  **過去の氏名・住所も検索条件として指定できる**（住民票・戸籍の附票の
  記載どおりに記入。条件ごとに手数料が加算）。正確には
  **「検索条件に含めなければ漏れうる」**
- 未登記の不動産は検索対象にならない。ただし**固定資産税の家屋補充
  課税台帳に載っていることがある**ので「調べる手段がない」ではない。
  正確には**「全国的な登記名義検索では拾えない」**

→ 制度の限界を過大に描いて項目の必要性を水増ししない。

また相続登記は義務化され（取得を知ってから3年以内）、
住所等変更登記も2年以内の義務となった。

→ **これは SeiZen の載せる基準（§13-1）を直接動かす。**
「どこにどの不動産があるか」の一覧は、2026年2月以降、
**家族が自力で調べられるようになった部分がある**。
だが漏れるのは「登記が現状と食い違っているもの」と「未登記のもの」。
**つまり、調べられないのは "登記に出てこないもの" に絞られた。**

### 1-10. 扉が閉まったときの本当のコスト ―― 最高裁 令和6年（再調査）

§1-5 で後見申立ての動機を見たが、**閉まった後に何が起きるか**は
調べていなかった。定義が固まったので調べ直した。

| | 数字 |
|---|---|
| 審理期間 | 2か月以内 72.0%／4か月以内 93.8% |
| 鑑定の実施 | 3.8%のみ。費用は10万円以下が87.1% |
| **後見人と本人の関係** | **親族以外 82.9%**（司法書士11,875件／弁護士8,794件）。親族は17.1% |
| 申立書に親族候補を記載 | **21.3%** |

→ **重いのは「時間」ではない。**手続き自体は数か月で終わる。
重いのは**家族ではない専門職が後見人になり、本人が亡くなるまで
財産を管理し続ける**こと。8割以上が親族以外で、そもそも申立ての
時点で親族を候補に書いているのが2割しかない。

**これが「今のうち」の重さの正体。**手続きが遅くなるのではなく、
**家族の手から離れる**。

### 1-11. 期限が二本走っている ―― 法務省・地方税法（再調査）

**(1) 相続登記の義務化（令和6年4月1日〜／法務省 一次資料）**

- 取得を知った日から3年以内。**正当な理由なく違反すると10万円以下の過料**
- **令和6年4月1日より前の相続で未登記のものは、令和9年3月31日まで**
  ―― 2026年9月時点で**残り約6か月**（2026-09-24 訂正。以前「約1年半」と
  書いていたのは計算誤り）
- 登録免許税の免税措置も令和9年3月31日まで。★ただし**価額100万円
  以下の土地に限り、建物は対象外**（国税庁 0018003-081-01）。
  「今やれば安い」と一般化して書かない ―― 相続登記一般の期限と
  並べると、すべての相続登記が免税になるように読める
- 所有者不明土地の発生原因の**約3分の2が相続登記の未了**

**相続人申告登記**（令和6年4月新設）＝ 間に合わないときの逃げ道。
単独で申出可・押印不要・法定相続分の確定不要・非課税。**ただし**：

- 遺産分割に基づく相続登記の申請義務は履行できない
- **権利関係を公示しないので、売却・抵当権設定には別途 相続登記が必要**

→ **「申告したから終わった」と思うと、売るときに詰まる。**
把握しておくべき手続きの分岐。なお初月の利用は全国で約1,100件と
極めて少ない。

**(2) 固定資産税の現所有者申告（地方税法384条の3／令和2年4月〜）**

- **現所有者と知った日の翌日から3か月**（自治体により「翌年1月31日」との
  遅い方）―― **相続登記の3年より短い**
- **10万円以下の過料**（自治体の税条例。広島市・白河市とも明記）
- **相続登記とは別の手続き。**登記が済めば不要だが、していない間は必要。
  ★**「必ず出す」ではない** ―― 3か月以内に相続登記が完了していれば
  申告は不要（横浜市の公式ページに明記）。登記が済めば不要なのは
  地方税法384条の3の構造上どこも同じで、自治体差があるのは期限の細部
- 申告しないと、市が相続人代表者を指定して納税通知書を送る
- **未登記家屋も対象**（市町村へ「未登記家屋所有者変更届」）

→ 相続登記の義務化は報道され認知が進んだが、**税の届出が別にあり、
しかも期限が3か月と短いことは知られていない**。登記の話だけ調べていても
出てこない。**§13-1 に当たるのは情報そのものではなく、手続きの存在**。

## 2. 調査から出た構造

### 2-1. 本人の進行と、そこに現れる不動産

| 本人の状態 | 不動産に起きること | 裏づけ |
|---|---|---|
| 元気なうち | 何も起きない。話し合いも約7割が未実施 | §1-6（70%／32.5%） |
| 判断力が落ちる | **本人の手でしかできない手続きが閉じる**。売る・貸す・解約する・書類に署名する、が全部止まる | §1-5（後見申立て動機の36.0%が不動産の処分。任意後見は全国2,795人） |
| 施設に入る・転居する | **家が空く**。管理・固定資産税・片付けが家族に移る。本人名義のまま | §1-1（転居39.0%＋施設入居10.0%） |
| 亡くなる | 名義変更で詰まる。書類の在り処が分からない。専門家に頼む | §1-7（名義変更36.7%／委任64.2%）、§1-6（76.4%が保管場所不明） |

**重要なのは、この4段階が「順に進む」のではなく、
2段目で扉が閉まるということ。** 判断力が落ちた時点で、
本人にしかできないことは全部できなくなる。3段目・4段目で必要になっても、
もう取りに戻れない。

→ **「今のうち」の定義が、ここから決まる。**
「今のうち」＝**本人がまだ自分で動けるうちにしかできないこと**。
死ぬ前、ではなく、**判断力が落ちる前**。

### 2-2. 「今のうち」に入るものの基準

上の構造から、「今のうち」に入れるものは次の2条件のどちらかを満たすもの：

**(a) 本人の手でしかできない** ―― 本人の意思・署名・実印が要る。
代理が効かない。判断力が落ちたら後見を立てるしかなくなる（§1-5）。

**(b) 本人しか知らない** ―― 登記にも書類にも出てこない。
本人が失われると再現できない（§13-1）。2026年2月の制度変更で、
**登記に出てくるものは家族が調べられるようになった**ので、
この (b) は「登記に出てこないもの」に絞り込まれた（§1-9）。

この2条件は、前回「一本に絞ろうとして極端に振れた」ところ。
**軸はこの2つで、付随して整理したほうがいいものは当然ある**、という順番にする。

### 2-3. 落ちるもの（基準で落ちたことを記録する）

- **信託・任意後見の契約の有無** … §1-2（1.3%）§1-5（2,795人）より、
  ほぼ全員が「該当なし」。項目として立てない。ただし
  **(a) の説明としては使う**（「今やらないと後見を立てることになる」）
- **認知症になったときの対処法** … §1-4（0.6%）。重いが遭遇率が低い。
  「今のうち」の主題にしない
- **物件の一覧・所在そのもの** … §1-9 により家族が調べられる。
  漏れるのは「検索条件に含めなかった旧姓・旧住所」と「未登記」だけ
- **名義変更の手順** … §1-7。専門家に委任する割合が高い（いい相続
  2023, n=400 で64.2%）。SeiZen は手順ではなく材料を持つ
  ★**数字の注意**：国交省 令和6年調査にも「名義変更を行った 64.2%」
  という**別の**数字がある（§1-3 と同じ図表）。偶然の一致なので、
  引用時は必ず出典を書き分ける
- **家財・片付け** … 実家の片付けで困ったこと（n=446, 2026年5月）は
  荷物の多さ35.7%／親の抵抗22.6%／思い出の品18.4%。
  巨大な問題だが**労力の問題であって、思い出せない・調べられない問題ではない**。
  §13-1 に当たらない
- **仏壇・形見・誰に渡すか** … 不動産ではなく**本人の希望カテゴリ**が
  持つ（§8 二度書きしない、§13 領域をまたいで形を持ち出さない）。
  一度「家財のうち本人しか行き先を知らないもの」として拾い直したが、
  **領域が違う**ので落とす（§3-2 で確定）

## 3. 二つの面の定義（2026-09-19 対話で確定）

項目を並べる前に、**この二つの面が何のためにあるか**を定める。
ここが定まっていなかったため、v23〜v25 は指摘のたびに
Todo →（残件リスト）→ 固定リスト → 材料 と解釈が振れ続けた。

### 3-0. 定義

**「今のうち」＝ 本人がまだ判断し、意思を伝えられるうちにしか、
確認・対応できないこと。**

期限は死亡ではなく、**判断力が落ちるまで**（§2-1、2段目で扉が閉まる）。
やらなければ取り返せない。

**「そのとき」＝ 実際に病気や死亡が起きたときに家族が何をすればよいかを、
今のうちに把握・整理しておくこと。**

★**そのときに開いて読む画面ではない。**
今これを見て、そのとき何が起きるかを分かっておくための面。
相続登記なら、それが必要になること・どんな手続きになるか・
何を用意しておく必要があるかを、**前もって確認できているか**を見る。

### 3-1. 二つの面の関係

| | 今のうち | そのとき |
|---|---|---|
| 性格 | **実行する** | **把握しておく** |
| 取り返し | つかない（本人が失われると終わり） | つく（そのときやればよい） |
| 例 | 境界の口約束を書面にする | 相続登記の手続きと必要書類を把握する |

**右は左を動かす理由になる。** 名義が実態と違うなら、そのとき
「先代から二段で遡る」ことになる ―― それが右に見えているから、
今のうちに片づける動機が立つ。**今やれば軽い**が、左右を繋ぐ。

### 3-2. この面の構造

**「今のうち」は単一の群。**

v24 では ①本人に確認すること ②本人の意向 ③今のうちに対応すること
の3群に割ったが、**①と③は同じ項目の進み方の違いでしかない**。

- 境界が未確認 → 本人に確認する
- 確認したら口約束だった → 書面にする

同じ「境界」という一つの項目が進んだだけ。2群に割ると、自宅では
境界が①から消えて③に現れる、という見え方になる。
**一つの項目として持てば、状態が進むだけで、消えたり現れたりしない。**

**②「本人の意向」は落とす。**

- 「住まなくなったらどうしたいか」「施設へ移ったら戻る前提か」は、
  **必要になった時点で本人に聞ける**。施設入居は本人が生きていて
  会話できる場面がほとんどで、聞けないほど判断力が落ちているなら
  そもそも本人の意向として成立しない
- **本人が失われると消える情報ではなく、本人が失われれば存在しなく
  なる情報**。境界の口約束（相手も高齢で確認先が消える）とは性質が違う
- §13-1「必要になったとき家族が思い出せない・調べられないことか」を
  満たさない
- なお §1-2 の数字（対策ありで家が動く1.5倍）は**話し合いという行為**
  の効果であって、**SeiZen が記録として持つべき根拠にはならない**。
  この二つを混同しないこと

**仏壇・形見・誰に渡すか**も落とす。不動産ではなく
**本人の希望カテゴリ**が持つ（§8 二度書きしない、§13 領域をまたいで
形を持ち出さない）。引き継ぎ書の「落としたもの」に最初から書いてある。

**「当面の管理を誰に頼みたいか」**も落とす。本人が指名しても相手の
引受やその時点の家族の事情で変わるので、**基準(a)（本人の手でしか
できない）を満たさない**。そのとき側に一度だけ出す。

### 3-3. 項目が立つ条件

**固定リストではない。残件リストでもない。**

- **何が項目として立つかは、下エリア（項目設計 1〜7）の入力が決める。**
  ローンが無ければ引き落としの項目は出ない。土地だけなら火災保険も
  家に入る方法も出ない。`neededDocs()` が書類でやっているのと同じ構造
- **立った項目は、確認・対応が済んでも消えない。** 状態と内容を持ち
  続ける。済んだものが消えると「確認が残っていない」しか見えなくなり、
  §11（空欄と該当なしを分ける）§12（必要な状態がどこまで成立したか）
  に反する。**分母が動くと進捗は数えられない**

### 3-4. やってはいけない表示（v23〜v25 で繰り返した失敗）

1. **残件リスト。** 未確認のものだけ拾って並べる。済むと行が消え、
   全部済むと節ごと消える
2. **「残っていない」「未決 1／6件」などの集計。** 残りいくつ、は
   進捗管理の数字であって、**その家がどうなっているかを示していない**
3. **「〜を決める」だけの Todo。** 今それを見ても、そのとき何が
   起きるかが分からない。**決まっていることは決まった内容**を出す
4. **型や枠を先に固定して、中を埋める。** 「電気・水道・ガス」を
   トップレベルの固定項目にするなど。**登録されているものだけ**が立つ

### 3-5. 要不要を決める基準

項目を思いついた順に並べない。次の問いに答えられないものは落とす。

**「今のうち」＝ 本人が失われると取り返しがつかないか。**

「知っておくと良い」は基準ではない。知っていても結論が変わらないもの、
本人以外からも辿れるもの、物として残るものは落ちる。

**「そのとき」＝ そのとき家族が、知らないと組み立てられないか。**

★**「誰かが教えてくれるか」は基準ではない**（検討の途中で一度この線に
振れたが、ずれている）。借主から「家賃はどこへ」と連絡が来て気づいても、
**気づいた後に何をするかは分からない**。気づくかどうかではなく、
**気づいた後に組み立てられるか**で判断する。

逆に、気づけば誰でもできること（電気を止める、家を見に行く）は、
書いても**家族の振る舞いが変わらない**ので落とす。

### 3-6. 項目（2026-09-19 確定）

★**画面上は「今のうち」を型で分けない。** 下の型1/2/3は検討のための
道具であって、節の名前ではない。境界は「聞く」で始まり、口約束だと
分かれば「書面にする」へ進む ―― **同じ項目が型をまたいで進む**ので、
型で節を割ると §3-2 で統合した意味が消え、項目が消えたり現れたりする。

#### 今のうち（単一の群）

**1行が「確認の状態」と「対応」を別に持つ。** 排他にしない
―― 対応が必要になると確認済みである事実が消える作りは誤り。

| 立つ条件 | 項目 | 対応（確認の結果として出る） |
|---|---|---|
| 土地がある | 境界と、隣との取り決め | 書面にない取り決めがあれば → 書面にする |
| 私道等の取り決めがある | 私道・通行・配管の、書面にない取り決め | 同上 |
| 建物がある | 増改築と、その登記 | 登記が未対応なら → 表題登記をしておく |
| 名義が前の代のまま | 土地・建物の名義が、前の代のままになっている | 本人が遺産分割協議に加わって名義を決める |

★**私道は対象を「私道そのもの」から「書面にない取り決め」へ寄せた。**
持分は登記で分かり、承諾先も登記から辿れる。今しか取れないのは
登記に出ない当事者間の約束（維持費の負担、掘削の承諾）のほう。

★**「今しかできない」の言い過ぎを直した。**「書面にするのは双方が
署名できるうちだけ」は誤り ―― 代が変わっても新しい所有者同士で合意は
できる。今しか取れないのは**何を合意したかを知っている当事者の記憶**。
増改築も「本人が判断できないと登記できない」のではなく、
**いつ・誰が建てたかを本人から聞けなくなる**のが問題。

★**定義は「今しかできない」のまま広げない。** 「今を逃すと難しくなる」
まで緩めると、片付けも書類整理も全部入る。合わないのは定義ではなく
**文のほう**なので、文を直す。

★**登録免許税の免税は書かない。** 免税は**価額100万円以下の土地に限り、
建物は対象外**（国税庁）。相続登記一般の期限と並べると、すべての
相続登記が免税になるように読める。

**落としたもの（理由つき）**

- **共有の経緯** … 知っていても分割協議の結論は変わらない。持分は登記で確定
- **権利証のありか** … 相続登記に権利証は不要（§1-7）
- **家に入る方法** … 鍵は家族も知っていて、物として残る
- **火災保険の告知／空き家のまま保つ** … 本人の判断能力と無関係で、
  空き家になった後に家族だけでできる。とくに「空けておけ」は**助言として
  誤り** ―― 貸せば収入になるし、放置すれば傷む。3,000万円控除を守れという
  目的化した助言で、SeiZen が言うことではない
- **状態を持たない知識**（控除の要件など）… 確認も対応もしないので項目に
  ならない。列に混ぜるとバッジが「該当なし」になって不自然。置き方は
  レイアウトの検討で別途決める

#### そのとき ―― **死亡のときだけ**

★**「住まなくなったとき」のトリガーは廃止した。** 生前に家が空くことは
事実として多いが（§1-1）、**そこで不動産に固有の手続きは発生しない**
―― 名義は動かず、契約も続く。トリガーを2つ置いていたのは、
**事実の重さと手続きの有無を混同**していた。

| 立つ条件 | 項目 |
|---|---|
| 常に | **市町村へ「現所有者の申告」を出す** ―― 知った日の翌日から3か月、過料10万円以下。★**「必ず」ではない**：3か月以内に相続登記が終われば申告は不要（横浜市の公式ページに明記）。登記が済めば不要なのは地方税法384条の3の構造上どこも同じで、自治体差があるのは期限の細部。登記されていない建物もこの届出で扱う |
| 常に | **法務局へ相続登記を申請する** ―― 3年以内、過料10万円以下。前の代の名義が残っていれば、そちらの遺産分割から先に片付ける。間に合わないときは相続人申告登記 ―― ただし義務が消えるだけで、売却・抵当権設定には別途 相続登記が要る<br>※**必要な資料はここに従属**。独立項目にしない（項目設計 §6）。中身と所在は下エリアの「関係書類」が持ち、ここは件数の参照だけ |
| ローンがある | **金融機関へ死亡を連絡し、団信の弁済手続きをする** ―― ★「保険金を請求する」は実態と違う。家族が保険金を受け取るのではなく、保険金がローンの弁済に充てられる。黙っていても消えない。**保険法95条で3年**（死亡日の翌日から起算）。フラット35は任意加入なので付いていないこともある |
| 貸している・借りている | **賃貸・借地の引継ぎ** ―― 貸主の地位を誰が継ぐか、敷金の返還義務、賃料の振込先 |

**落としたもの**

- **売る・貸すときに必要な手続き** … 読んでも家族が何をするか出てこず、
  書いてあるのは「できません」。後見は預貯金も施設契約も同じ制度に乗る
  話で不動産固有ではない（§13）
- **未登記家屋の名義変更** … 現所有者の申告と同じ窓口・同じ性格で二重。
  本文に一行入れるだけにした
- **管理委託の引継ぎ** … 契約者が変わるのは家族も分かる。続けるかは判断で
  あって、知識が要る手続きではない
- **空いた家を誰が見るか／電気・水道・ガス** … 気づけば誰でもできる。
  書いても家族の振る舞いが変わらない

#### 期限の並びが、この面の要

**3か月（固定資産税の現所有者申告）→ 3年（相続登記）。**
先に来るのは税のほうで、**そちらの方が知られていない**。
加えて「今のうち」には令和9年3月31日が走っている。

## 4. この項目設計が前回と違うところ

1. **「そのとき」を死亡に固定していない。** §1-1 の数字が、
   家が空くきっかけの過半は生前だと示している。生前に住まなく
   なったときと、亡くなったときの2トリガーに分けた
2. **「今のうち」の期限を判断力に置いた。** 死ぬ前ではなく、
   **扉が閉まる前**（§1-5）。これで「今のうち」が
   「早めにやっておくといいこと」という曖昧なものでなくなる
3. **登記で取れるものを持たないと決めた。** §1-9 の制度変更を
   §13-1 に当てた結果、(b) が「登記に出てこないもの」に絞り込まれた
4. **項目を並べることをゴールにしていない。** §3 が定めたのは
   **二つの面が何のためにあるか**であって、項目の一覧ではない。
   何が立つかは下エリアの入力が決めるので、一覧は最初から書けない
5. **認知症・共有・境界を主題にしていない。** §1-4 の 0.6%／2.2%。
   重さと遭遇率を混同しない

## 6. 「前の代の相続登記」の持ち方（2026-09-23）

§3-6 の「名義が前の代のまま → 本人が遺産分割協議に加わって名義を決める」を、
フォームとして何を持つかまで詰めた。

### 6-0. 以前の形が使えなかった理由

状態4択＋自由記入4つ（経緯・話合いの状況／次にすること／確認する人／確認する時期）。

- 家族が何を書けばよいか分からない（全体設計 §1 が挙げる判断を利用者に返している）
- SeiZen が中身を読めない。状態・次の対応・「そのとき」の案内に使えない
- 次にすること・誰が・いつまでは SeiZen が出すもの（全体設計 §9・§10）。
  利用者の文が SeiZen の文を上書きしていた
- 「確認済み」が「相続登記の完了を確認した」の意味で、ラベルから読めない

### 6-1. 調べたこと

| 事実 | 出どころ |
|---|---|
| 遺産分割協議書と印鑑証明書に、**相続登記での有効期限はない** | リーガルスクエア https://souzoku.legalsquare.net/qanda/qanda-3387/ ／かもめ司法書士事務所 https://kamome-shihousyoshi.jp/2025/04/10/ |
| 取得する相続人が判断能力を欠くと、**後見なしでは登記申請ができない** | 中野相続手続センター https://www.tokyo-intl.com/15302379596969 |
| 協議がまとまる前に相続人が亡くなると、**その相続人の相続人全員が協議に加わる**（数次相続） | 東京新宿法律事務所 https://www.shinjuku-law.jp/services/inheritance/column/isanbunkatumae-sibou/ ／相続の窓口 https://www.souzoku-mado.jp/3.7.26 |
| 期限：2024年4月1日より前の相続は2027年3月31日まで、以後は知った日から3年 | §1-11（法務省） |

→ **本人の手でしかできない部分がどこで終わるかは、取得する人で割れる。**
本人以外が取得するなら、協議書に署名した時点で終わる。
本人が取得するなら、登記の申請まで本人が要る。

### 6-2. 持つもの（2026-09-24 改訂）

フォームは1列で、選択肢はプルダウンにせず並べて見せる（開くまで見えない・長い選択肢が切れるため）。

改訂の理由（ユーザー指摘）：
- **相続登記は遺産分割協議書を経るとは限らない。** 遺言がある／相続人が1人／
  法定相続分での共有登記、の道がある。以前は協議の道しか想定しておらず、
  遺言のある家・相続人が1人の家では答えようがなかった
- **協議の当事者は、SeiZen の対象者（父）とは限らない。** 名義人が母の親なら
  加わるのは母。「本人」と書いて両者を混同していた。画面では「本人」を使わず
  続柄（父・母）で書く
- **印鑑証明書は、取得するのが当事者以外のときだけ聞く。** 登記には協議書と
  全員の印鑑証明書が要り、亡くなった人の印鑑証明書は取れない。渡す前に当事者が
  亡くなると、当事者の相続人全員が「協議書が真正に作られた」旨の証明書に実印を
  押すことになる。取得するのが当事者なら、当事者の印鑑証明書は問わない

| 欄 | 値 | SeiZen が何に使うか |
|---|---|---|
| 前の代の名義が残っているか | 残っている／残っていない／まだ確かめていない | 状態 |
| どれが前の代の名義か | 土地・建物 | 本文・権利関係・そのとき |
| 前の代の名義人 | 名前（権利関係の「名義」と連動） | 名義の図・権利関係 |
| 名義人は父から見て | 父の親／父の祖父母／母の親／その他 | 協議の当事者（父・母・特定しない） |

## 7. 「境界・越境の取り決め」の持ち方（2026-09-24）

§6 の前の代の相続登記と同じ考え方（答えだけを持ち、状態・次の対応・くわしくは
SeiZen が出す）を、境界の法的事実に合わせて当てた。型は写していない（§13）。

### 7-0. 以前の形が使えなかった理由

状態の手選び＋「父に聞けたか」「ある・ない」「誰・何で確認したか」＋自由記入

### 7-3b. 作り直したこと（2026-09-24 ユーザー指摘）

- **図を前の代から写していた。** 名義の図（枠→矢印→枠）は「誰から誰へ移るか」の図。境界は

- **「知っているのは父と当時の隣の人だけ」は曖昧で煽る言い方だった。** 事実（登記にも図面にも
  残らない／隣も代替わり・売却で変わる）で書く。「建て替える」も外した ―― 境界の確定が
  求められると調べてあるのは売却だけ

- **境界の位置の目印を聞かず、図も出していなかった。** 一番よくある「塀の中心」に図が無かった。目印（塀の中心／

- **こちら側・隣側の違いを「塀の厚みぶんのずれ」で描いていた。** 違いは誰の土地に立つ・誰の塀か。面が境界に
  揃う塀は、壁も基礎も持ち主の側に丸ごと置き、「共有の塀／隣の塀／こちらの塀」と書き添える

- **取り決めを1件として持っていた。** 取り決めは隣ごとに別（西隣とは塀の中心、北隣の枝が越境…）。隣を複数
  選ぶと別々の取り決めが1枚の図に混ざり、食い違った（「境界は塀の隣側の面」と「隣の塀が越境」が同居）。

  図・説明・次にすることも隣ごと。状態は、どれか1つでも口頭のまま・分からなければ対応が必要、全部書面なら書面あり
- 図の向き：北を向いて見る図面の約束で、西・北の隣は左、東・南の隣は右。図の上の両端に方位

- **境界を確かめる場面を「売るとき」だけにしていた（2026-09-24）。** 調べた範囲が売却だけだったから
  で、考えた結果ではなかった。分ける（分筆）・隣が測量する（こちらが立会い・署名）も同じく隣と
  署名し合う。一文は「土地を売る・分けるとき、隣が測量するときには、隣と境界を確かめて署名し合う」
  ＋「口頭で決めたことも、覚書にしておけば、そのとき見せて確かめるだけで済む」。書面が無いと困る、で
  止めない（だから書面にする、が答えられていなかった）。「隣も代替わり・売却で変わる」「新しい持ち主は
  知らない」は何も言っていないので外した。国庫帰属はまれなので、くわしく（境界を確かめる場面）へ

## 8. 「私道・通行・配管の取り決め」の持ち方（2026-09-24）

§7 の境界と同じ考え方（答えだけを持ち、状態・次の対応・くわしくは SeiZen が出す）を当てる。
ただし境界の持ち方（隣ごとの取り決め・目印・越境の持ち主）は写さない。事実の形が違う。

### 8-0. 事実の形 ―― 境界と並べる

| | 境界・越境 | 私道・通行・配管 |
|---|---|---|
| 何の事実か | 2軒の間の**1本の線**の上の合意 | **向きのある依存**：ある土地のために、別の土地を通る・管を通す |
| 相手 | 隣（線を挟んだ家） | 隣とは限らない：前の私道の持ち主（何軒か）、隣の敷地、離れた土地 |
| 向き | 線は両家に対称。向きは越境したものの持ち主で決まる | 向きが事実の中心。**この家が使っている**（依存）と**この家が使わせている**（負担）で、家族のすることが逆になる |
| 目に見えるか | 塀・杭は見える | 通り道は見える。**地中の管は見えない**。他人の管の図面は家族には見られない（給水装置台帳は個人情報で、使用者・所有者だけ） |
| いつ問題になるか | 売る・分ける・隣が測量する（署名し合う） | 管を**直す**・建て替える（掘る）、**売る**（買主の金融機関）。相手が代替わり・売却したとき |

→ **"側"は、相手の土地ごとに1件を持ち、その中に「何を・誰のために」を並べる**（`links[{ land, who, uses:[{ what, by }] … }]`）。
`by` は「誰のための通行・管か」：ours＝この家が相手の土地を使う／theirs＝相手がこの家の土地を使う。
同じ相手との間に両向きがありうる（古い分筆の土地で、こちらの水道管が隣を通り、隣の下水管がこちらを通る）ので、
向きは件ではなく使い方ごとに持つ。前の私道は「この家が使う」向きだけ（持分を持っていても、他の家の分は私道の共有のルールで扱う）。

### 8-1. 調べたこと ―― いつ・誰の承諾が要るか

| 事実 | 出どころ |
|---|---|
| 他の土地に管を通すしかないときは、**前もって知らせれば足りる**（民法213条の2、2023年4月施行）。償金は要るが、**承諾料に応じる義務はない**。所在不明の持ち主には公示で通知 | 法務省 共有私道ガイドライン第2版（2022年6月）／RETIO No.127「所有者不明私道への対応ガイドライン（第2版）について」https://www.retio.or.jp/wp-content/uploads/2024/11/127-066.pdf |
| 共有の私道の共有者は、自分の給水管を私道の下に置くことを、**持分に応じた使用として単独でできる**。持合（数筆を出し合う）型は、互いに明示・黙示の通行地役権があると考えられる | 同上（事例11・12） |
| それでも実務では、**水道事業者が承諾書を求める例がある**（承諾書がないことは給水を断る理由にならない：厚労省通知 平成28年）。**下水道管理者の約7割が、私道共有者全員の同意を独自に求めていた**（国交省 2021年1月調査） | 同上 |
| 私道に面した家を売るとき、持分が無いと、**買主の金融機関が通行・掘削承諾書を求める**ことが多い（無いとローン不可・減額）。承諾書に「所有者が変わっても引き継ぐ」条項があれば買主にも効く | 家売り隊 https://homenever.com/excavation-consent-form/ ／URUHOME https://uruhome.net/shidoumochibunn/ |
| 位置指定道路を日常の生活に欠かせない通路として使う人は、通行を妨げられない（最判平成9年12月18日、車の通行も） | https://www.sak-office.jp/hanrei/gyousei2/28 |
| 登記のない通行地役権でも、通路として**見て分かる**状態で使われていれば、相手の土地の買主に主張できる（最判平成10年2月13日） | retpc https://www.retpc.jp/archives/25398/ |
| 他人と共用の排水管が地中にあると知りながら説明せずに売ると、**契約不適合責任**を問われる（売主が浄化槽の費用を払っていたことから、知っていたと認定） | 三井住友トラスト不動産 https://smtrc.jp/useful/knowledge/jyuyojiko/2024_10.html |
| 地中の管は、買主が建てる段になって初めて見つかる（東京地裁 2023年11月6日。この事案は支障が小さく責任なし） | retpc https://www.retpc.jp/archives/31707/ |
| 自分の給水装置の図面は、水道局で使用者・所有者（委任状で代理人）が閲覧できる。他人のものは見られない | 東京都水道局 https://www.waterworks.metro.tokyo.lg.jp/jigyosha/zumen/hoho ／鹿児島市 給排水台帳 |
| 非課税の私道は、**課税明細書に載せない自治体がある**。名寄帳・所有不動産記録証明（2026年2月〜）には出る | 鷲頭事務所／名義変更の窓口 https://www.meigi-henkou.jp/syoyuu-fudousan-nayosetyou |

**下エリア調査の訂正：** 「私道は掘削承諾が無いと水道・ガスの工事・再建築ができない」（下エリア §9 の表）は、
2023年4月以降は言い過ぎ。法律では通知で足り、承諾書を求めるのは事業者と金融機関の運用。

### 8-2. 今のうちの線 ―― 境界と同じ理屈は使えない

承諾そのもの（承諾書をもらうこと）は**今のうちではない**。承諾が要るのは管を直す・建て替える・売るときで、
頼む相手はその時点の持ち主（登記で辿れる）。法律も通知で足りる側に動いた。家族が後からできる。

父が失われると取り返せないのは、次の2つ：

1. **書面にない取り決めの中身**（境界と同じ）。私道の補修費の分け方、承諾料を払ったか、建て替えのとき管をどうするか。
   知っているのは父と相手だけで、相手の土地が売られると買主には当然には及ばない
2. **他人の管がこの家の土地の下を通っていること**（私道・配管に固有）。地面の上から見えず、登記にも出ず、
   他人の給水装置の図面は家族には見られない。取り決めが無くても、あること自体を知っているのは父だけ。
   知らずに売れば契約不適合、知らずに掘れば管を壊す

今のうちではないもの：前の道が私道か・持分（登記・道路台帳）、この家の管の経路（自分の図面は水道局・市で見られる）、
取り決めのない通行・配管の承諾書を今もらうこと。

**両基準に照らすと：**
- 今のうち（本人が失われると取り返しがつかないか）… 上の1・2。記録した時点で今のうちの分は済む（2 は取り決めが無くても「確認済み」）
- そのとき（知らないと組み立てられないか）… 私道の持分を相続登記に入れること。課税明細書に載らないので、知らないと漏れる

### 8-3. 図：真上から見た区画図（2026-09-25 改訂）

**初版は図を置かず、誤りだった。** 「関係の事実なので1行の文で言い切れる／経路の位置を持たないので描けば作り話」
として、使い方ごとに札と文を並べたが、行が答えの言い直しの羅列になった（「自宅は、右隣の土地を通って出入りしている」

## 9. 「建物の変更・登記」の持ち方（2026-09-25 調査、2026-09-26 実装）

§7・§8 と同じ考え方（答えだけを持ち、状態・文は答えから出す）を当てる。境界・私道の持ち方
（entries／links…）と図の描き方は写さない。事実の形が違う。計画ファイルの建物の案（§3 の表）は
仮説として扱い、下の調査で確かめ直した。

### 9-0. 事実の形 ―― 境界・私道と並べる

| | 境界・越境 | 私道・通行・配管 | 建物の変更・登記 |
|---|---|---|---|
| 何の事実か | 2軒の間の線の上の合意 | 向きのある依存 | **建物そのものが、いつ・誰の手で・どう変わったか**（出来事）と、**その結果、記録が実物とずれているか** |
| 相手 | 隣 | 私道の持ち主・隣・離れた土地 | 人ではなく**記録**：法務局（登記）と市町村（家屋課税台帳）。両者は別々に更新される |
| 時間 | 持たない（今の合意） | 持たない | 中心。登記は**登記したときの建物の写し**で、申請しない限り変わらない。工事と登記は別の手続きで、工事を頼んでも登記まではされない |
| 見えるか | 塀・杭は見える | 管は見えない | 建物は見えるが、**どこが後から足した部分かは見て分からない**。登記・課税の記録は家族も取れる |
| いつ問題になるか | 売る・分ける・隣の測量 | 直す・売る | 売る・担保に入れる（買主の金融機関）、**相続登記**（新しい名義人に1か月の義務がかかる） |

（増築は所有を示す書類が要り、取り壊しは要らない）。この物件の建物は1つ（権利関係の建物）なので、
離れ・車庫などの別棟は「別棟を建てた」という変更の1件として持つ。

### 9-2. 今のうちの線 ―― 境界・私道の理屈は使えない

境界・私道の今のうちは「書面にない取り決めの中身」だった。建物の変更には相手との取り決めが無い。
登記の手続きそのものも、父が亡くなった後に相続人が申請できる（30条）。日付も不詳で出せる。

**父がいなくなると取り返せないのは、床面積が増えた変更（増築・別棟）について、増えた部分が父の
ものだと示す手がかり**：工事の書類（確認済証・請負契約書・領収書…）のありかと、頼んだ会社
（工事完了引渡証明書を出せるのはその会社だけ）。書類が無くても今なら父の上申書で申請できるが、
父が判断できなくなると後見人を立てるまで申請できず、亡くなった後は相続人全員の実印・印鑑証明書を
付けた上申書になる。市町村も把握していなければ（課税明細書に出ていなければ）、変更があったこと
自体が父の記憶にしか無い。

今のうちではないもの：
- 登記の手続きそのもの（書類がそろっていれば、相続人の1人で申請できる）
- 取り壊し・減築の登記（所有を示す書類が要らない。取毀証明書が無ければ上申書）
- 登記と課税の記録を比べること（家族が今でも後でもできる）
- 確認申請をしたか（役所の台帳記載事項証明書で家族が調べられる）
- いつ変えたか（不詳で申請できる。書類探しの手がかりとして任意で持つ）
- 誰が費用を出したか（付合で父のもの。出したのが子なら子自身が知っている。贈与税は税理士の話）

**両基準に照らすと：**
- 今のうち … 増えた変更が未登記（か分からない）で、所有を示す書類が無い・分からないとき。
  書類のありかを記録した時点で、今のうちの分は済む（登記は家族が後からできる）
- そのとき … 相続登記をすると、相続した人に1か月以内の表題変更登記の義務がかかる（51条2項）ので、
  先に（同時に）土地家屋調査士へ。未登記の別棟は相続登記では名義が移らない（表題登記＋未登記家屋の
  所有者変更届）

- **v1（不可）：** 3本の帯（今の建物／登記／課税明細書）。右の説明を描き直しただけで、何の絵でもなかった
  （「無理くり図にした感じ」）。続けて図を捨てて札に逃げかけ、「なんで極端に振れるの？検討するのが力」と止められた
- **家の図の欠点「位置が多すぎる」は、登記が持つものまで畳めば解ける。** 登記が持つのは各階の床面積と建物の数
  （不登法44条）だけ。どこを工事しても、違いは「何階か・玄関から見てどちら側か・本体に接するか離れるか」に収まる
- **登記そのものが家の図を持つ**（法務局の各階平面図：壁芯を実線、階ごと、上の階は1階の位置を点線、附属建物は符号：
  不動産登記規則83条）。その上に今の家を重ねれば、ずれがそのまま絵になる
- **v2（不十分）：** 登記の形を実線の四角にし、外に変更の箱を付けた →「四角にプラスしただけ」。変更（減る・無くなる）が
  表せない。「本体」の語も分かりづらい
- **v3（採用）：** 形を2つ重ねる。今の家＝地の色と実線の一続きの外形（増えれば出っ張り、減れば欠ける。本体と箱に分けない）。
  登記の形＝灰色の太い線を、地の色・斜線の上、今の家の線の下に敷く（同じところは縁取り、違うところだけ別の道を通る。
  増築の付け根を横切る線で「登記はここまで」が見える）。登記に入っていない部分＝斜線、取り壊したが登記に残る部分＝
  灰色の線の中の白抜き。部屋・大きさ・時期は描かない。玄関を下にする（方角は家族が即答できない。境界と同じ）
- 図を出すのは、登記と今の建物がずれている（か分からない）変更があるときだけ。札は置かない（1枚に全部の変更が載り、
  説明は変更1件で2〜3行に収まる）

### 9-5. 画面に出るもの

  くわしく（売る・担保に入れるとき／所有を示す書類／課税されていなかったとき／義務と費用）
- 権利関係の表：建物の列に「登記と今の建物」（登記に入っていない・残っている変更があるときだけ）
- そのとき（相続登記「この物件では」）：増築が入っていない → 51条2項で相続した人に1か月の義務、先に表題変更、

### 9-6. 落としたもの

- 誰が費用を出したか … 付合（民法242条）で建物の持ち主のもの。出したのが子なら子自身が知っている。贈与税は税理士の話
- 確認申請をしたか … 役所の台帳記載事項証明書で家族が調べられる（くわしくで触れる）
- 屋根の葺き替え・用途の変更（構造・種類の変更登記）… 売る・担保で問題にされるのは床面積と建物の有無。遭遇しても
  土地家屋調査士が現況を測るときに一緒に扱う
- 変更の正確な位置・大きさ … 登記の手続きには要らない（調査士が建物全体を測り直す）。図は答えから場所だけ置く

### 9-7. 作り直したこと（2026-09-26 ユーザー指摘）

- **文：**「増築・取り壊しの登記は所有者の義務です」は何の登記を誰がするのか言っていなかった →
  「所有者に登記（表題変更登記・滅失登記）を申請する義務」。「どこに仕舞ったかは父に聞かないと分かりません」は
  砕けていて、事実でなく言い回しだった → 何が記録に残らないのか（請け負った会社と書類の保管場所は、登記にも
  課税明細書にも載らない）で言う。次にすることの補足も「保管場所は父に確かめます」（境界の行も同じく直した）
- **フォーム：** 登記・課税明細書・工事の書類を別々の問いにし、選択肢の形（丸いボタン／大きな札）を選択肢の長さで
  場当たりに決めていた（「分けた理由は？テキトウ？」）。3つとも「この変更がどの記録に載っているか」の答えで、
  行の図が描く事実と同じなので、1つの問い「この変更の記録」にまとめ、左に名前・右に選択肢を揃える。
  場所・階・どの部分・いつごろも「場所と時期」の1つに同じ並べ方でまとめる（左の名前の幅は2つの問いで揃える）
- **言い方の統一：** 登記・課税明細書は「載っている／載っていない」、取り壊しは「消えている／残っている」。
  工事の書類は「ある／見つからない／まだ探していない」、種類は正式名（工事請負契約書）。図の横の説明も
  フォームと同じ「登記／課税明細書／工事の書類」の3行にした。登記をまだ確かめていない部分は、図で
  「登記に載っていない」と同じ斜線にしていた → 薄い斜線で描き分ける
- **（続き）いつごろ：** 日付を自由記入にしていた → 年を選ぶ（建てた年〜今年、和暦を添え、先頭に「分からない」）
- **登記に載っている段：** 1行だけで終わっていた → 図（登記の形が今の家と重なる）と、家族にとっての意味
  （建物の登記を直さずに、そのまま相続登記ができる）を出す
- **一文が長すぎた（7行→5行でもまだ長い）：** なぜ必要か1文（登記を直す義務＋売るときのローン）と、なぜ今のうちか1文
  （今なら書類が足りなくても父の上申書で申請できる／この変更は課税明細書にも載らず、示せるのは父の記憶だけ）に。
  父が亡くなった後に相続人全員の上申書になることは、くわしく「所有を示す書類」へ
- **図の横の説明のバランス：** 課税明細書・工事の書類まで3行の表にして右の欄が詰まった → 説明は図を言葉で言うこと
  （変更の見出し＋登記の状態）だけ。課税明細書と書類が何を意味するかは次にすることの補足が言う。凡例は下にまとめて小さく
- **依頼が複数：** 「調査士に依頼する」が変更の数だけ並んだ → 依頼は1回で済むので1行にまとめ、補足の同じ文は1回だけ
- **「この変更の記録」を何に使うのかが画面から見えなかった：** 課税明細書と工事の書類の答えは、父なしで所有を
  示せるか（今のうちの判定）そのものなのに、次にすることの文に混ぜるだけだった → 図の下に「所有を示すもの」の欄
  （境界・私道の「用意できている書類」と同じ位置と作り）。変更ごとに、示すもの（課税明細書に載っていれば固定資産
  評価証明書、工事の書類は選んだ種類）と「足りる／あと◯種類」、まだ確かめていないもの。状態の判定も同じ数え方
  （評価証明書を含めて2種類以上で「書類あり」）。次にすることは「何をするか」だけに戻した
- **別棟の図の「玄関」：** 玄関側の別棟が玄関の字と重なり、自由記入で「建てた6畳」になった → 別棟・取り壊した建物は
  「何の建物か」を選ぶ（離れ／車庫／物置／その他）。玄関は玄関側の変更が無いところ（中央から順に探す）に置き、
  短い矢印のすぐ下に字
- **図の大きさ：** 家を 96×62 で描き、枠の4割しか使っていなかった → 枠（220px）いっぱいに（家 140×84、
  出っ張り・別棟も同じ比率）。表示範囲は描いたものの外形から決める。番号・字は11px以上、斜線は粗く。
  説明の2行目（登記の状態）に図と同じ見本を付けて凡例を兼ね、図と説明の上端を揃えた
- **図の中の変更が小さかった：** 家だけを大きくし、変わった部分の比率を変えていなかった → 主役は変わった部分。
  家 124×78 に出っ張り30・欠け24・別棟30（2階があるときは各66×58）
- **複数のときを確かめていなかった：** 同じ辺に2件／3辺／4件／2階を含む／2階に2件／玄関側に2件 を表にして撮った。
  2階の変更は1件しか描いていなかった → 変更ごとにその側を斜線、登記の形は残りの部分。玄関側に変更があると
  玄関がふさがった・またいだ → 玄関は中央に固定し、玄関側の変更は玄関の口の左右の半分へ振り分ける。
  図と説明は上下中央に揃える（説明が長いときも図が上に浮かない）
- **「まだ確かめていない」と出しながら、次にすることが無かった：** 取り壊しの登記を「後からできる」として外していた。
  画面に「まだ確かめていない」と出すもの（登記・課税明細書）には、必ず確かめる手（登記事項証明書／課税明細書で
  確かめる）を出す。登記をまだ確かめていない変更があれば状態は「未確認」（確認済みにしない：§11）。登記に載って
  いるか分からないうちは「調査士に依頼する」を出さない。次にすることの順は 確かめる → 書類を探す → 依頼する
- **図が左に寄り、説明と食い違った（同日）：** 家の位置を固定していて、右側だけに変更があっても左に寄った →
  描いたものの左右の外形を測り、枠の中央に寄せる。取り壊しで登記をまだ確かめていない部分を「登記に残っている」と
  同じ白抜きにしていた → 説明の見本と同じ薄い斜線。取り壊して登記からも消えた建物は番号だけが浮いた → かつての
  位置を薄い点線。確認は「何をしたか4種×登記3通り」の12通りと、変更の側4通りを並べ、説明の見本と図の塗りを
  1つずつ突き合わせた
- **見えない枠の中で中央に寄せていた（同日）：** 図を幅220pxの固定の枠に入れ、その中で中央に寄せたので、図の左端が
  文の左端と揃わず、説明との間も組み合わせで変わった（「何をしている？位置のバランス悪いよね？」）。枠をやめ、図の幅は
  描いたものの幅（1:1、最大220px）。左端は文に揃え、説明は図の右端のすぐ後ろ（17px）から残りの幅を使う。図と説明の
  文字の上下の中心を揃える。狭い幅（520px以下）で説明が170pxを切るなら図の下へ。
  2件以上の説明は、見出しを1行ずつにし、登記の状態は種類ごとにまとめて見本の横に番号を並べる（同じ状態が件数だけ
  並んで、説明が図の倍の高さになった）。2階を描くときの平面は縦を大きく（58→72）。
  確認は、行の中で「図の左端と文の左端のずれ／図と説明の間隔／上下の中心のずれ／図と説明の高さ」を12通り×3幅で測った
  （1px／17px／0〜1px。見えない枠の中の余白を測っても、行の中の見え方は分からない）
- **説明が左に寄りすぎた（同日）：** 前の直しで、説明を図の右端のすぐ後ろ（17px）から始めたため、図が狭いと説明も
  左に寄り、行の右半分が空いた。次に「説明の開始位置を固定する」案を出したが、「固定か、すぐ後ろか」の二択に自分で
  狭めていた（「バランスに応じて変えればいいだけだよね？」）。→ 図の左端は文に揃え、説明は文が要る幅で置き、行に
  残る余白を「図と説明の間」と「説明の右」に同じだけ配る（間は16px以上。上限を付けると余りが右に溜まった）。
  12通り×2幅で、間と右の余白の差は1px
- **根本のずれ（同日）：** 図と説明を別々の2つの物として扱い、間の余白ばかり調整していた（固定の枠／図のすぐ後ろ／
  余白を等分、のどれも変だった）。敷地を足す案も出したが「無理くり加えただけ」。説明は図の凡例なので、図のそばに
  寄せて1つのまとまり（間24px）にし、そのまとまりを行の中央に置く。内容が少なければ小さく中央に、多ければ行の幅
  いっぱいに広がる（内容量に応じて置き方が決まる）。12通りで、まとまりの左右の余白の差は1px
