# SeiZen｜不動産・住まい　「今のうち」「そのとき」　調査と項目

作成 2026-09-19。項目設計 §0 の「中央＝家族が実際にすること」のうち、
**今のうちに確認しておくこと**／**そのとき使うもの** に何を入れるかを決める。

起点は**本人の状態**。不動産はそこに現れる対象の一つであって、
物件の種別から入らない。

---

## 1. 調べたこと

前回は専門家の解説記事から論点を拾って失敗した。今回は
**n数のある調査と公的統計**を起点にし、解説記事は数値の裏づけにだけ使う。

### 1-1. 「そのとき」は死亡ではない ―― 国交省 令和6年空き家所有者実態調査

対象13,268世帯／回収6,294世帯（回収率約51%）、令和6年11〜12月。
令和7年8月公表。

**人が住まなくなった理由**（N＝1,170千戸）

| 理由 | 割合 |
|---|---|
| 死亡 | 43.9% |
| 別の住宅に転居 | 39.0% |
| 老人ホームなどの施設に入居 | 10.0% |
| 転勤など（一時的不在） | 3.7% |
| 入院など（一時的不在） | 1.2% |

**家が空くきっかけの過半（転居39.0＋施設入居10.0＋入院1.2＝50.2%）は、
本人が生きている間に起きている。** 相続で取得した空き家に限っても
死亡は58.3%で、残り約4割は生前に空いている。

→ 「そのとき」＝死亡、という置き方は事実に反する。
**本人が住まなくなる**という段階が、死亡とは別に立っている。

### 1-2. 生前の対策は、ほぼされていない ―― 同調査

**相続前の対策状況**（N＝742千世帯）

| | 割合 |
|---|---|
| 相続前に対策を講じていない | 77.0% |
| 相続前に対策を講じた | 23.0% |

対策の内訳（複数回答）

| 対策 | 割合 |
|---|---|
| 被相続人との話し合い | 16.7% |
| その他の対策 | 4.3% |
| 遺言の作成支援 | 1.8% |
| 後見制度や家族信託の活用 | **1.3%** |

そして**対策の有無で結果が変わっている**。対策無しの空き家は、
何もせずそのまま空き家として所有され続ける割合が**約1.5倍**
（対策無し45.1% / 対策有り29.4%）。

→ **実際にされている生前対策は「話し合い」だけ**。制度（信託・後見・遺言）は
合わせて3%台で、事実上使われていない。これは最高裁の統計とも一致する
（§1-5）。SeiZen が「今のうち」に置くべきは**制度の手続きではなく、
話し合いの中身**である。

### 1-3. 共有だと登記が止まる ―― 同調査

**登記または名義変更の有無**（N＝1,256千世帯、令和5年10月1日時点＝相続登記義務化前）

| 所有者の数 | いずれも行っていない |
|---|---|
| 1人（単独所有） | 12.5% |
| **2人以上（共有）** | **23.8%** |

空き家の種類別でも、使用目的のない空き家は17.6%と高い。

→ 共有は「揉める論点」として語られがちだが、数字に出ているのは
**手続きが止まる**という形。単独所有の約2倍。

### 1-4. 一方で、認知症・共有の「合意できない」は上位に出ない ―― 同調査

空き家として所有しておく理由（N＝323千世帯、複数回答）の下位：

| 理由 | 割合 |
|---|---|
| 所有者が複数で合意が困難 | 2.2% |
| **関係者が認知症などで意思決定できない** | **0.6%** |

上位は「物置として必要 55.8%」「解体費用をかけたくない 47.3%」
「住宅の古さ 37.0%」。

→ **重さと遭遇率を混同しない**（前回の反省）。認知症による凍結は
起きたときは深刻だが、空き家が放置される理由としては最下位に近い。
**「今のうち」を認知症対策の画面にしてはいけない。**

### 1-5. 本人の手でしかできない手続き ―― 最高裁 成年後見関係事件の概況（令和6年）

終局事件41,620件。**主な申立ての動機**（複数回答、母数＝終局事件総数）

| 動機 | 件数 | 割合 |
|---|---|---|
| 預貯金等の管理・解約 | 38,561 | 92.7% |
| 身上保護 | 30,599 | 73.5% |
| 介護保険契約 | 18,623 | 44.7% |
| **不動産の処分** | **14,990** | **36.0%** |
| 相続手続 | 10,855 | 26.1% |
| 保険金受取 | 7,132 | 17.1% |

そして利用者数（令和6年12月末）は総数253,941人のうち、
**任意後見はわずか2,795人**。

→ 前セッションが見つけた「**本人の手でしかできない手続き**」という型は、
n=1の体験記ではなく**国の統計で裏づく**。家庭裁判所に行く動機の
36.0%が不動産の処分であり、その時点で本人はもう自分で動けない。
かつ、事前に備える制度（任意後見）は全国で2,795人＝ほぼ使われていない。

**この型は項目設計に入れる。** ただし入れ方は「信託を契約しましたか」ではない
（§1-2・§1-4より、それは該当なしばかりになる）。

### 1-6. 家族は書類の在り処を知らない ―― すむたす 実家じまい意識調査

2025年11月20日〜12月6日、親世代60〜89歳 有効回答102名／
子世代30〜59歳 有効回答110名。**n が小さいので方向性としてのみ扱う。**

- 親子で実家について**話し合ったことがある 32.5%**（約7割が話し合いなし）
- 子世代の**76.4%が権利証などの保管場所を「把握していない」**
- 子が親に求めること：不用品整理 43.6% ／ **重要書類の整理 33.6%**
- 一方**親世代の76.5%が「協力してほしいことは特にない」**
- 話し合わない理由：親 63.1% ／ 子 43.6% が「まだ具体的に考えていない」

「約7割が話し合っていない」は、n=2,346 の三菱地所の調査
（2021年9月、40〜60歳代中心）の「**両親と相続について話したことがない 約70%**」
と一致する。桁の違う2調査で同じ数字が出ているので、この点は信頼できる。

→ **非対称が本体**。親は「渡すものは特にない」と思っており、
子は「書類がどこにあるか分からない」と思っている。
SeiZen が §9 で「問いは SeiZen 側が持つ」としているのは、まさにこの型に効く。

### 1-7. 詰まるのは名義変更 ―― 複数調査で一致

| 出どころ | n | 数字 |
|---|---|---|
| 日本トレンドリサーチ／ニーズ・プラス 2023年12月 | 1,000 | 不動産相続で大変だったことがある 54.6%／その1位 **名義変更 36.7%**／2位 親族間のすり合わせ 22.7%／**事前にやっておくべきことがあった 62.0%** |
| いい相続／鎌倉新書 2023（既出） | 400 | 専門家に任せた手続き：**不動産の名義変更（相続登記）64.2%**／戸籍収集 60.4% |
| 相続弁護士相談広場 2021（既出） | 226 | 困ったこと：何から手をつけたらよいか分からない 41.7% |

→ 名義変更は「1位で詰まる」かつ「6割強が自分でやらず専門家に投げる」。
**つまり SeiZen が手順を教える対象ではない。** 家族は専門家に頼む。
専門家に頼むときに必要なのは、**どの不動産が・誰の名義で・書類はどこか**
という材料である。SeiZen が持つべきはそこ。

### 1-8. 決まっていない ―― イエコン 2024年7月（n=1,000）

実家が戸建てで将来空き家になる予定／相続しそうな男女1,000人。

- 実家が空き家になった後どうするか：**「まだ決めていない」52.9%**
  （売却して現金化 16.4%／自分や親族が住む 11.7%）
- 相続したくない 53.2%／相続したい 46.8%
- 実家をなくすことに抵抗がある 55.2%

→ 過半が決めていない。**SeiZen は「結論を書かせる欄」を作ってはいけない。**
決まっていないことが普通の状態であり、それは §11 の状態として持つべきもの。

### 1-9. 制度が変わった ―― 所有不動産記録証明制度（2026年2月2日施行）

登記名義人本人・その相続人等が、**全国どの法務局でも、人を基準に
その人名義の不動産を一覧で取れる**ようになった。手数料1,600円（書面請求）。

ただし限界がある（★当初「漏れる」と書いていたが強すぎた。訂正済み）：

- 検索は「氏名の前方一致＋住所の市区町村一致」等で行われる。
  **過去の氏名・住所も検索条件として指定できる**（住民票・戸籍の附票の
  記載どおりに記入。条件ごとに手数料が加算）。正確には
  **「検索条件に含めなければ漏れうる」**
- 未登記の不動産は検索対象にならない。ただし**固定資産税の家屋補充
  課税台帳に載っていることがある**ので「調べる手段がない」ではない。
  正確には**「全国的な登記名義検索では拾えない」**

→ 制度の限界を過大に描いて項目の必要性を水増ししない。

また相続登記は義務化され（取得を知ってから3年以内）、
住所等変更登記も2年以内の義務となった。

→ **これは SeiZen の載せる基準（§13-1）を直接動かす。**
「どこにどの不動産があるか」の一覧は、2026年2月以降、
**家族が自力で調べられるようになった部分がある**。
だが漏れるのは「登記が現状と食い違っているもの」と「未登記のもの」。
**つまり、調べられないのは "登記に出てこないもの" に絞られた。**

### 1-10. 扉が閉まったときの本当のコスト ―― 最高裁 令和6年（再調査）

§1-5 で後見申立ての動機を見たが、**閉まった後に何が起きるか**は
調べていなかった。定義が固まったので調べ直した。

| | 数字 |
|---|---|
| 審理期間 | 2か月以内 72.0%／4か月以内 93.8% |
| 鑑定の実施 | 3.8%のみ。費用は10万円以下が87.1% |
| **後見人と本人の関係** | **親族以外 82.9%**（司法書士11,875件／弁護士8,794件）。親族は17.1% |
| 申立書に親族候補を記載 | **21.3%** |

→ **重いのは「時間」ではない。**手続き自体は数か月で終わる。
重いのは**家族ではない専門職が後見人になり、本人が亡くなるまで
財産を管理し続ける**こと。8割以上が親族以外で、そもそも申立ての
時点で親族を候補に書いているのが2割しかない。

**これが「今のうち」の重さの正体。**手続きが遅くなるのではなく、
**家族の手から離れる**。

### 1-11. 期限が二本走っている ―― 法務省・地方税法（再調査）

**(1) 相続登記の義務化（令和6年4月1日〜／法務省 一次資料）**

- 取得を知った日から3年以内。**正当な理由なく違反すると10万円以下の過料**
- **令和6年4月1日より前の相続で未登記のものは、令和9年3月31日まで**
  ―― 2026年9月時点で**残り約1年半**
- 登録免許税の免税措置も令和9年3月31日まで。★ただし**価額100万円
  以下の土地に限り、建物は対象外**（国税庁 0018003-081-01）。
  「今やれば安い」と一般化して書かない ―― 相続登記一般の期限と
  並べると、すべての相続登記が免税になるように読める
- 所有者不明土地の発生原因の**約3分の2が相続登記の未了**

**相続人申告登記**（令和6年4月新設）＝ 間に合わないときの逃げ道。
単独で申出可・押印不要・法定相続分の確定不要・非課税。**ただし**：

- 遺産分割に基づく相続登記の申請義務は履行できない
- **権利関係を公示しないので、売却・抵当権設定には別途 相続登記が必要**

→ **「申告したから終わった」と思うと、売るときに詰まる。**
把握しておくべき手続きの分岐。なお初月の利用は全国で約1,100件と
極めて少ない。

**(2) 固定資産税の現所有者申告（地方税法384条の3／令和2年4月〜）**

- **現所有者と知った日の翌日から3か月**（自治体により「翌年1月31日」との
  遅い方）―― **相続登記の3年より短い**
- **10万円以下の過料**（自治体の税条例。広島市・白河市とも明記）
- **相続登記とは別の手続き。**登記が済めば不要だが、していない間は必要。
  ★**「必ず出す」ではない** ―― 3か月以内に相続登記が完了していれば
  申告は不要（横浜市の公式ページに明記）。登記が済めば不要なのは
  地方税法384条の3の構造上どこも同じで、自治体差があるのは期限の細部
- 申告しないと、市が相続人代表者を指定して納税通知書を送る
- **未登記家屋も対象**（市町村へ「未登記家屋所有者変更届」）

→ 相続登記の義務化は報道され認知が進んだが、**税の届出が別にあり、
しかも期限が3か月と短いことは知られていない**。登記の話だけ調べていても
出てこない。**§13-1 に当たるのは情報そのものではなく、手続きの存在**。

## 2. 調査から出た構造

### 2-1. 本人の進行と、そこに現れる不動産

| 本人の状態 | 不動産に起きること | 裏づけ |
|---|---|---|
| 元気なうち | 何も起きない。話し合いも約7割が未実施 | §1-6（70%／32.5%） |
| 判断力が落ちる | **本人の手でしかできない手続きが閉じる**。売る・貸す・解約する・書類に署名する、が全部止まる | §1-5（後見申立て動機の36.0%が不動産の処分。任意後見は全国2,795人） |
| 施設に入る・転居する | **家が空く**。管理・固定資産税・片付けが家族に移る。本人名義のまま | §1-1（転居39.0%＋施設入居10.0%） |
| 亡くなる | 名義変更で詰まる。書類の在り処が分からない。専門家に頼む | §1-7（名義変更36.7%／委任64.2%）、§1-6（76.4%が保管場所不明） |

**重要なのは、この4段階が「順に進む」のではなく、
2段目で扉が閉まるということ。** 判断力が落ちた時点で、
本人にしかできないことは全部できなくなる。3段目・4段目で必要になっても、
もう取りに戻れない。

→ **「今のうち」の定義が、ここから決まる。**
「今のうち」＝**本人がまだ自分で動けるうちにしかできないこと**。
死ぬ前、ではなく、**判断力が落ちる前**。

### 2-2. 「今のうち」に入るものの基準

上の構造から、「今のうち」に入れるものは次の2条件のどちらかを満たすもの：

**(a) 本人の手でしかできない** ―― 本人の意思・署名・実印が要る。
代理が効かない。判断力が落ちたら後見を立てるしかなくなる（§1-5）。

**(b) 本人しか知らない** ―― 登記にも書類にも出てこない。
本人が失われると再現できない（§13-1）。2026年2月の制度変更で、
**登記に出てくるものは家族が調べられるようになった**ので、
この (b) は「登記に出てこないもの」に絞り込まれた（§1-9）。

この2条件は、前回「一本に絞ろうとして極端に振れた」ところ。
**軸はこの2つで、付随して整理したほうがいいものは当然ある**、という順番にする。

### 2-3. 落ちるもの（基準で落ちたことを記録する）

- **信託・任意後見の契約の有無** … §1-2（1.3%）§1-5（2,795人）より、
  ほぼ全員が「該当なし」。項目として立てない。ただし
  **(a) の説明としては使う**（「今やらないと後見を立てることになる」）
- **認知症になったときの対処法** … §1-4（0.6%）。重いが遭遇率が低い。
  「今のうち」の主題にしない
- **物件の一覧・所在そのもの** … §1-9 により家族が調べられる。
  漏れるのは「検索条件に含めなかった旧姓・旧住所」と「未登記」だけ
- **名義変更の手順** … §1-7。専門家に委任する割合が高い（いい相続
  2023, n=400 で64.2%）。SeiZen は手順ではなく材料を持つ
  ★**数字の注意**：国交省 令和6年調査にも「名義変更を行った 64.2%」
  という**別の**数字がある（§1-3 と同じ図表）。偶然の一致なので、
  引用時は必ず出典を書き分ける
- **家財・片付け** … 実家の片付けで困ったこと（n=446, 2026年5月）は
  荷物の多さ35.7%／親の抵抗22.6%／思い出の品18.4%。
  巨大な問題だが**労力の問題であって、思い出せない・調べられない問題ではない**。
  §13-1 に当たらない
- **仏壇・形見・誰に渡すか** … 不動産ではなく**本人の希望カテゴリ**が
  持つ（§8 二度書きしない、§13 領域をまたいで形を持ち出さない）。
  一度「家財のうち本人しか行き先を知らないもの」として拾い直したが、
  **領域が違う**ので落とす（§3-2 で確定）

## 3. 二つの面の定義（2026-09-19 対話で確定）

項目を並べる前に、**この二つの面が何のためにあるか**を定める。
ここが定まっていなかったため、v23〜v25 は指摘のたびに
Todo →（残件リスト）→ 固定リスト → 材料 と解釈が振れ続けた。

### 3-0. 定義

**「今のうち」＝ 本人がまだ判断し、意思を伝えられるうちにしか、
確認・対応できないこと。**

期限は死亡ではなく、**判断力が落ちるまで**（§2-1、2段目で扉が閉まる）。
やらなければ取り返せない。

**「そのとき」＝ 実際に病気や死亡が起きたときに家族が何をすればよいかを、
今のうちに把握・整理しておくこと。**

★**そのときに開いて読む画面ではない。**
今これを見て、そのとき何が起きるかを分かっておくための面。
相続登記なら、それが必要になること・どんな手続きになるか・
何を用意しておく必要があるかを、**前もって確認できているか**を見る。

### 3-1. 二つの面の関係

| | 今のうち | そのとき |
|---|---|---|
| 性格 | **実行する** | **把握しておく** |
| 取り返し | つかない（本人が失われると終わり） | つく（そのときやればよい） |
| 例 | 境界の口約束を書面にする | 相続登記の手続きと必要書類を把握する |

**右は左を動かす理由になる。** 名義が実態と違うなら、そのとき
「先代から二段で遡る」ことになる ―― それが右に見えているから、
今のうちに片づける動機が立つ。**今やれば軽い**が、左右を繋ぐ。

### 3-2. この面の構造

**「今のうち」は単一の群。**

v24 では ①本人に確認すること ②本人の意向 ③今のうちに対応すること
の3群に割ったが、**①と③は同じ項目の進み方の違いでしかない**。

- 境界が未確認 → 本人に確認する
- 確認したら口約束だった → 書面にする

同じ「境界」という一つの項目が進んだだけ。2群に割ると、自宅では
境界が①から消えて③に現れる、という見え方になる。
**一つの項目として持てば、状態が進むだけで、消えたり現れたりしない。**

**②「本人の意向」は落とす。**

- 「住まなくなったらどうしたいか」「施設へ移ったら戻る前提か」は、
  **必要になった時点で本人に聞ける**。施設入居は本人が生きていて
  会話できる場面がほとんどで、聞けないほど判断力が落ちているなら
  そもそも本人の意向として成立しない
- **本人が失われると消える情報ではなく、本人が失われれば存在しなく
  なる情報**。境界の口約束（相手も高齢で確認先が消える）とは性質が違う
- §13-1「必要になったとき家族が思い出せない・調べられないことか」を
  満たさない
- なお §1-2 の数字（対策ありで家が動く1.5倍）は**話し合いという行為**
  の効果であって、**SeiZen が記録として持つべき根拠にはならない**。
  この二つを混同しないこと

**仏壇・形見・誰に渡すか**も落とす。不動産ではなく
**本人の希望カテゴリ**が持つ（§8 二度書きしない、§13 領域をまたいで
形を持ち出さない）。引き継ぎ書の「落としたもの」に最初から書いてある。

**「当面の管理を誰に頼みたいか」**も落とす。本人が指名しても相手の
引受やその時点の家族の事情で変わるので、**基準(a)（本人の手でしか
できない）を満たさない**。そのとき側に一度だけ出す。

### 3-3. 項目が立つ条件

**固定リストではない。残件リストでもない。**

- **何が項目として立つかは、下エリア（項目設計 1〜7）の入力が決める。**
  ローンが無ければ引き落としの項目は出ない。土地だけなら火災保険も
  家に入る方法も出ない。`neededDocs()` が書類でやっているのと同じ構造
- **立った項目は、確認・対応が済んでも消えない。** 状態と内容を持ち
  続ける。済んだものが消えると「確認が残っていない」しか見えなくなり、
  §11（空欄と該当なしを分ける）§12（必要な状態がどこまで成立したか）
  に反する。**分母が動くと進捗は数えられない**

### 3-4. やってはいけない表示（v23〜v25 で繰り返した失敗）

1. **残件リスト。** 未確認のものだけ拾って並べる。済むと行が消え、
   全部済むと節ごと消える
2. **「残っていない」「未決 1／6件」などの集計。** 残りいくつ、は
   進捗管理の数字であって、**その家がどうなっているかを示していない**
3. **「〜を決める」だけの Todo。** 今それを見ても、そのとき何が
   起きるかが分からない。**決まっていることは決まった内容**を出す
4. **型や枠を先に固定して、中を埋める。** 「電気・水道・ガス」を
   トップレベルの固定項目にするなど。**登録されているものだけ**が立つ

### 3-5. 要不要を決める基準

項目を思いついた順に並べない。次の問いに答えられないものは落とす。

**「今のうち」＝ 本人が失われると取り返しがつかないか。**

「知っておくと良い」は基準ではない。知っていても結論が変わらないもの、
本人以外からも辿れるもの、物として残るものは落ちる。

**「そのとき」＝ そのとき家族が、知らないと組み立てられないか。**

★**「誰かが教えてくれるか」は基準ではない**（検討の途中で一度この線に
振れたが、ずれている）。借主から「家賃はどこへ」と連絡が来て気づいても、
**気づいた後に何をするかは分からない**。気づくかどうかではなく、
**気づいた後に組み立てられるか**で判断する。

逆に、気づけば誰でもできること（電気を止める、家を見に行く）は、
書いても**家族の振る舞いが変わらない**ので落とす。

### 3-6. 項目（2026-09-19 確定）

★**画面上は「今のうち」を型で分けない。** 下の型1/2/3は検討のための
道具であって、節の名前ではない。境界は「聞く」で始まり、口約束だと
分かれば「書面にする」へ進む ―― **同じ項目が型をまたいで進む**ので、
型で節を割ると §3-2 で統合した意味が消え、項目が消えたり現れたりする。

#### 今のうち（単一の群）

**1行が「確認の状態」と「対応」を別に持つ。** 排他にしない
―― 対応が必要になると確認済みである事実が消える作りは誤り。

| 立つ条件 | 項目 | 対応（確認の結果として出る） |
|---|---|---|
| 土地がある | 境界と、隣との取り決め | 書面にない取り決めがあれば → 書面にする |
| 私道等の取り決めがある | 私道・通行・配管の、書面にない取り決め | 同上 |
| 建物がある | 増改築と、その登記 | 登記が未対応なら → 表題登記をしておく |
| 名義が前の代のまま | 土地・建物の名義が、前の代のままになっている | 本人が遺産分割協議に加わって名義を決める |

★**私道は対象を「私道そのもの」から「書面にない取り決め」へ寄せた。**
持分は登記で分かり、承諾先も登記から辿れる。今しか取れないのは
登記に出ない当事者間の約束（維持費の負担、掘削の承諾）のほう。

★**「今しかできない」の言い過ぎを直した。**「書面にするのは双方が
署名できるうちだけ」は誤り ―― 代が変わっても新しい所有者同士で合意は
できる。今しか取れないのは**何を合意したかを知っている当事者の記憶**。
増改築も「本人が判断できないと登記できない」のではなく、
**いつ・誰が建てたかを本人から聞けなくなる**のが問題。

★**定義は「今しかできない」のまま広げない。** 「今を逃すと難しくなる」
まで緩めると、片付けも書類整理も全部入る。合わないのは定義ではなく
**文のほう**なので、文を直す。

★**登録免許税の免税は書かない。** 免税は**価額100万円以下の土地に限り、
建物は対象外**（国税庁）。相続登記一般の期限と並べると、すべての
相続登記が免税になるように読める。

**落としたもの（理由つき）**

- **共有の経緯** … 知っていても分割協議の結論は変わらない。持分は登記で確定
- **権利証のありか** … 相続登記に権利証は不要（§1-7）
- **家に入る方法** … 鍵は家族も知っていて、物として残る
- **火災保険の告知／空き家のまま保つ** … 本人の判断能力と無関係で、
  空き家になった後に家族だけでできる。とくに「空けておけ」は**助言として
  誤り** ―― 貸せば収入になるし、放置すれば傷む。3,000万円控除を守れという
  目的化した助言で、SeiZen が言うことではない
- **状態を持たない知識**（控除の要件など）… 確認も対応もしないので項目に
  ならない。列に混ぜるとバッジが「該当なし」になって不自然。置き方は
  レイアウトの検討で別途決める

#### そのとき ―― **死亡のときだけ**

★**「住まなくなったとき」のトリガーは廃止した。** 生前に家が空くことは
事実として多いが（§1-1）、**そこで不動産に固有の手続きは発生しない**
―― 名義は動かず、契約も続く。トリガーを2つ置いていたのは、
**事実の重さと手続きの有無を混同**していた。

| 立つ条件 | 項目 |
|---|---|
| 常に | **市町村へ「現所有者の申告」を出す** ―― 知った日の翌日から3か月、過料10万円以下。★**「必ず」ではない**：3か月以内に相続登記が終われば申告は不要（横浜市の公式ページに明記）。登記が済めば不要なのは地方税法384条の3の構造上どこも同じで、自治体差があるのは期限の細部。登記されていない建物もこの届出で扱う |
| 常に | **法務局へ相続登記を申請する** ―― 3年以内、過料10万円以下。前の代の名義が残っていれば、そちらの遺産分割から先に片付ける。間に合わないときは相続人申告登記 ―― ただし義務が消えるだけで、売却・抵当権設定には別途 相続登記が要る<br>※**必要な資料はここに従属**。独立項目にしない（項目設計 §6）。中身と所在は下エリアの「関係書類」が持ち、ここは件数の参照だけ |
| ローンがある | **金融機関へ死亡を連絡し、団信の弁済手続きをする** ―― ★「保険金を請求する」は実態と違う。家族が保険金を受け取るのではなく、保険金がローンの弁済に充てられる。黙っていても消えない。**保険法95条で3年**（死亡日の翌日から起算）。フラット35は任意加入なので付いていないこともある |
| 貸している・借りている | **賃貸・借地の引継ぎ** ―― 貸主の地位を誰が継ぐか、敷金の返還義務、賃料の振込先 |

**落としたもの**

- **売る・貸すときに必要な手続き** … 読んでも家族が何をするか出てこず、
  書いてあるのは「できません」。後見は預貯金も施設契約も同じ制度に乗る
  話で不動産固有ではない（§13）
- **未登記家屋の名義変更** … 現所有者の申告と同じ窓口・同じ性格で二重。
  本文に一行入れるだけにした
- **管理委託の引継ぎ** … 契約者が変わるのは家族も分かる。続けるかは判断で
  あって、知識が要る手続きではない
- **空いた家を誰が見るか／電気・水道・ガス** … 気づけば誰でもできる。
  書いても家族の振る舞いが変わらない

#### 期限の並びが、この面の要

**3か月（固定資産税の現所有者申告）→ 3年（相続登記）。**
先に来るのは税のほうで、**そちらの方が知られていない**。
加えて「今のうち」には令和9年3月31日が走っている。

## 4. この項目設計が前回と違うところ

1. **「そのとき」を死亡に固定していない。** §1-1 の数字が、
   家が空くきっかけの過半は生前だと示している。生前に住まなく
   なったときと、亡くなったときの2トリガーに分けた
2. **「今のうち」の期限を判断力に置いた。** 死ぬ前ではなく、
   **扉が閉まる前**（§1-5）。これで「今のうち」が
   「早めにやっておくといいこと」という曖昧なものでなくなる
3. **登記で取れるものを持たないと決めた。** §1-9 の制度変更を
   §13-1 に当てた結果、(b) が「登記に出てこないもの」に絞り込まれた
4. **項目を並べることをゴールにしていない。** §3 が定めたのは
   **二つの面が何のためにあるか**であって、項目の一覧ではない。
   何が立つかは下エリアの入力が決めるので、一覧は最初から書けない
5. **認知症・共有・境界を主題にしていない。** §1-4 の 0.6%／2.2%。
   重さと遭遇率を混同しない
