# SeiZen｜不動産・住まい　土地（建物の無い土地）　調査と項目

作成 2026-10-01。種別が「土地」の物件で、今のうち・そのとき・下の部屋に何を載せるかの
方向を決める。前提は `土地_カテゴリー検討.md`（カテゴリーは分けない／物件（間取り）とは
別の形で持つ／家に付く田畑はその家に入れる）。

判定の基準は戸建て・マンションと同じ：

- 今のうち＝父が失われると取り返しがつかないか（(a) 父の手でしかできない／(b) 父しか知らない）
- そのとき＝そのとき家族が、知らないと組み立てられないか
- 2段階：①書いたら家族の振る舞いが変わるか → ②物件ごとの記録か、SeiZen が持つ知識か

起点は父の状態（元気なうち→判断力が落ちる→施設→亡くなる）。土地はそこに付いてくる対象で、
地目の教科書（田・畑・山林…）から入らない。

## 1. 調べたこと

### 1-1. 持っている土地の形

| 事実 | 数字 | 出どころ |
|---|---|---|
| 住んでいる土地**以外**の土地を持つ世帯 | 775万世帯（**13.9%**）。うち住む土地を持たず、それ以外だけ持つ 112万世帯 | 国交省 令和5年世帯土地統計 |
| 世帯が持つ土地の面積の内訳 | **山林 53.7%／農地 34.8%**／現住居の敷地 7.0% ほか | 同上 |
| 住む土地以外の宅地の取得 | **相続・贈与 59.1%** | 同上 |
| 住む土地以外の宅地の使われ方 | 建物の敷地 51.0%／**使っていない（空き地・原野）30.7%**／建物以外に利用（駐車場・資材置場など）16.1% | 同上 |
| 住む土地以外の土地の取得の経緯（意識調査） | **相続 73.2%**／購入 29.1%（n=354） | 国交省 令和5年 土地問題に関する国民の意識調査 |
| その土地の今 | **父・母以外が住む・使う 54.0%**／誰も使わず管理だけ 35.3%／使わず管理もしない 10.5%（n=354） | 同上 |
| 使っていない理由 | 相続したが使う予定が無い 49.0%／体力・後継者不足（農地・山林）23.6%（n=157） | 同上 |

→ 父が持つ建物の無い土地は、**相続で受け継いだ田畑・山林**が中心で、**半分は誰かが使っている**。
残りの多くは使う予定が無い。

### 1-2. 前の代の名義のまま ―― 宅地より田畑・山林で多い

| 事実 | 数字 | 出どころ |
|---|---|---|
| 登記名義人が亡くなっている農地＋そのおそれがある農地 | 約52万ha＋約50.9万ha＝**全農地の約2割** | 農水省 相続未登記農地等の実態調査（令和3年） |
| 登記簿だけでは所有者の所在が分からない土地 | 宅地 14.5%／農地 17.4%／**林地 25.6%** | 国交省 地籍調査（平成28年度） |
| 森林の面積のうち、所有者が森林のある市町村に住んでいない | **24%** | 林野庁 資料（森林経営管理法の概要） |
| 不在村の森林所有者で、相続のとき何も手続きをしなかった | **17.9%** | 国交省 H23 不在村所有者アンケート（同資料） |

### 1-3. 登記からは見つからない土地

| 事実 | 出どころ |
|---|---|
| 固定資産税の課税標準が**30万円未満の土地は課税されず、納税通知書に載らない**。山林・原野で起きやすい。家族は通知書から土地の存在を知れない | 地方税法の免税点／各市町村 |
| 所有不動産記録証明（2026年2月2日〜）は、名前と住所で全国の登記を探す。**前の代の名義のまま**の土地、**登記の住所が古い**土地、旧姓の土地は出てこないことがある | 法務省／司法書士の解説（下の出典） |

→ 通知書にも父の名前の証明書にも出ない土地がある。ただし §1-8 のとおり、祖父の名義でも
証明書は請求できる。**見つからないのは、どの代の、どこの土地かの見当がつかないとき**。

### 1-4. 現地のどこにあるか、どこまでか ―― 山林・農地

| 事実 | 数字・中身 | 出どころ |
|---|---|---|
| 地籍調査の進み具合 | 全体 53%／**林地 47%**（令和5年度末） | 林野庁 森林境界の明確化（令和6年12月） |
| 林地で地籍調査が進まない理由 | 公図の精度が低い／**所有者の高齢化で現地の立会いができない**／所有者不明・境界の情報が無い | 同上 |
| 森林の境界が決まらない理由（林業者の見立て、複数回答 n=121） | **相続などで持っているが、自分の山がどこか分からない人が多い 64.5%**／地籍調査が進まない 45.5%／高齢で立会いできない 39.7% | 農水省 平成27年 森林資源の循環利用に関する意識・意向調査 |
| 境界を決めるとき、何を手がかりにするか | 尾根・谷・樹種の違い・空中写真から推測し、**最後は所有者の証言と合意**で確定する | 林野庁 同上 |
| 国が引き取る制度で、申請の段階で却下された理由 | 85件中 **境界が明らかでない 23件**／通路として使われている 22件／添付書類不足 37件 | 法務省 相続土地国庫帰属制度の統計（令和8年8月31日） |

→ 地番と面積は登記で取れる。現地のどこかは台帳の地図で辿れる（§1-8）。辿れないのは、
測量されていない森林の境界の線。

### 1-5. 使わせている関係 ―― 口約束が多い

| 事実 | 出どころ |
|---|---|
| 農地の貸し借りは農業委員会の許可（農地法3条）か、市町村・農地バンクを通す手続きが要る。**許可の無い貸し借りは効力を生じない**（同3条6項） | 農地法／各市町村 |
| 許可の無い貸し借り（いわゆるヤミ小作）は、顔なじみ同士の口約束で起きる。多くの市町村・農業委員会が注意を出している。**相続のとき、貸し手・借り手が分からなくなる** | 宇和島市・一関市・つくば市・九十九里町ほか |
| 許可を得た農地の賃貸借は、解約に都道府県知事の許可が要る（農地法18条）。借りている人の権利が強い | 農地法 |
| 無償で使わせている（使用貸借）関係は、**借りている人が亡くなると終わり、貸している父が亡くなっても終わらない**（民法597条3項） | 民法 |

★口約束がどれだけあるかの全国の数字は見つからなかった。市町村の注意喚起の多さと、§1-1 の
「半分は誰かが使っている」までが根拠。

### 1-6. 亡くなったときに走る届出 ―― 戸建てに無いもの

| 届出 | 相手 | 期限 | 罰則 | 出どころ |
|---|---|---|---|---|
| 森林の土地の所有者届出 | 森林のある市町村 | 所有者になった日から**90日**。分割前でも法定相続人の共有として出し、分割後に出し直す | 過料10万円以下 | 森林法10条の7の2／林野庁 |
| 農地の相続の届出 | 農地のある市町村の農業委員会 | 知った時から**10か月** | 過料10万円以下 | 農地法3条の3／農水省 |
| 現所有者の申告・相続登記 | 市町村・法務局 | 3か月・3年 | 戸建てと同じ | 既存調査 §3-6 |

相続登記の登録免許税は、**評価額100万円以下の土地なら免税**（令和9年3月31日まで）。戸建てでは
「すべての相続登記が免税に読める」として書かなかった（`今のうち-そのとき_調査と項目.md` §3-6）が、
山林・田畑ではこれがそのまま当たることが多い。

### 1-8. 家族が自分で辿れる経路（2026-10-01 再検討で追加）

§2-3 の初版は「父しか知らない」を前提にしていた。辿れる経路を調べ直した。

| 経路 | 分かること | 出どころ |
|---|---|---|
| 全国農地ナビ（eMAFF農地ナビ） | 農地ごとの所在・地番・地目・面積・**貸借の種類と期間**を、誰でも地図で見られる。農業委員会の窓口では所有者・耕作者の名前も見られる | 農水省 |
| 林地台帳・林地台帳地図（市町村、2019年〜） | 森林の所在・地番・林小班・**境界の測量の実施状況**。相続人は個人情報を含む全項目の提供を受けられる | 森林法191条の4／各市町村 |
| 所有不動産記録証明 | 相続人その他の一般承継人は、**祖父など前の代の名義人についても**戸籍を添えて請求できる | 法務省／政府広報 |
| 農地の賃借権の時効取得 | 許可の無い貸し借りでも、賃料を払って耕作を続けた人は、**農地法3条の許可なしに賃借権を時効取得しうる**（最判平16.7.13） | 判例 |

→ 農地の場所と貸借は公の台帳にある。森林の場所も台帳にあり、境界が測量済みかも分かる。
台帳に無いのは **森林の、測量されていない境界の線** と **許可の無い貸し借りの中身** だけ。

## 2. 判定

### 2-0. 起点 ―― 亡くなったとき家族が困ることから（2026-10-01 改め）

再検討の版は「父に聞かないと分からないか」だけで項目を見て、台帳で辿れるものを落としていた。
大前提は**父が亡くなったとき家族が困らないよう、情報を整理しておくこと**。父に聞けるかは、
その中で「いつ・誰が埋めるか」を決める一要素にすぎない。台帳で辿れるのも、**土地があること・
どこの市町村かを家族が知っていれば**の話。

| そのとき家族が困ること | 整理しておく情報（記録） | 埋めるのに父が要るか | SeiZen が出すこと（知識） |
|---|---|---|---|
| 土地があること・どこかを知らない（通知書が来ない土地、前の代の名義の土地） | まとまりごとの所在（市町村・地名）と、今の使われ方（田畑・山林・宅地） | **要る**。家族は課税明細書に載るものしか分からない | 記録証明（前の代の名義でも）・名寄帳・農地ナビ・林地台帳での確かめ方 |
| 名義が前の代のまま、誰の相続から片づけるか | 登記の名義人（父／祖父など） | 要る（どの代の土地かは父の記憶。登記で裏を取れる） | 二段の分割になること。父が加わる分割は今のうち |
| 誰かが使っている。誰に連絡し、どんな関係か | 使っている人・連絡先・関係（賃料の有無・農業委員会を通したか） | **要る**。口約束の中身は父と相手しか知らない。台帳には許可を通したものだけ、名前は窓口でしか見られない | 関係の扱い（続く／相続人を縛らない／時効の主張／無償は父の死で終わらない） |
| 草刈り・山の管理が止まる | 頼んでいる先（森林組合・近所の人）と連絡先 | 要る（相手は知っていても、家族は相手を知らない） | 誰に知らせるか |
| 期限を知らない | ―（使われ方と所在から決まる） | ― | 森林の届出90日・現所有者の申告3か月・農地の届出10か月・相続登記3年 |
| 要らないが、どうすればよいか分からない | 使われ方（誰も使っていない） | ― | 土地だけは放棄できない・国が引き取る制度 |
| 書類が見つからない | 貸し借りの契約書・境界の資料のありか | 要る | 何に要るか |

→ **土地で家族が困らないための中心は、記録（どこに・何の土地が・誰の名義で・誰が使い・誰に
頼んでいるか）を整理しておくこと。** その記録の多くは父に聞かないと埋まらない。

2-3 の「今のうち」は、この記録とは別物：父の判断・署名が要る**行為**（前の代の分割・登記の住所・
宅地の取り決めの書面化）だけを指す（既存調査 §3-0）。記録を埋めることは今のうちの項目ではなく、
下の部屋（材料）の役目。再検討の版はこの2つを混同し、「今のうちが薄い＝土地で整理するものが薄い」と
読んでいた。

### 2-1. 1件の単位 ―― 筆ではなく「1か所のまとまり」

- 筆の数・地番・面積は登記と名寄帳で取れる（第2段階：記録として持たない）
- 家族が問われるのは **場所（どこの土地か）** と **使われ方（誰が使っているか）**。届出（農業委員会・
  森林・現所有者の申告）は**市町村ごと**に出す
- → **1件＝同じ市町村の、同じ使われ方の土地のまとまり**（「長野の田んぼ」「裏山」）。筆数・地番は
  聞かない（地番は分かれば書ける欄にとどめる）

★「1つの家が何筆持つか」は調べても数字が見つからなかった。1件をまとまりにすれば、
この数字に設計が左右されない。

### 2-2. 宅地（更地・駐車場・人に貸している底地）は土地の側

`土地_カテゴリー検討.md` §3 の未決。**建物が無い**ので、住む人・建物の変更・ローンの問いが立たない
点は田畑・山林と同じ。一方、境界と隣・私道の取り決めは戸建てと同じ事実が成り立つ（更地にも隣がある。
国庫帰属の却下も境界・通路が上位）。

→ **土地の側に置き、境界・私道の問いは戸建てのフォームをそのまま使う**（同じ事実なので形を作り直さない。
同じ領域の中なので §13 の持ち出しにも当たらない）。

### 2-3. 今のうちの判定 ―― 土地に固有の行為は立たない（2026-10-01 再検討）

| 立つ条件 | 項目 | 基準 | 根拠 |
|---|---|---|---|
| 常に | 前の代の名義 | (a) | §1-2。前の代の遺産分割には父が加わる。判断力が落ちると後見を立てるしかない。戸建てと同じ問い |
| 常に | 登記の住所 | (a) | マンション §5-2 と同じ。直すのは父の申請か申出 |
| 宅地 | 境界と隣との取り決め／私道・通行・配管 | (b) | 戸建てと同じ（既存調査 §7・§8） |

**初版から落としたもの（理由）**

- **田畑・山林の現地の場所と境界** … 場所は農地ナビ・林地台帳で辿れる（§1-8）。台帳に無いのは森林の
  測量されていない境界の線だけで、それが要るのは売る・国に引き取ってもらう・伐採するときに限られる
  （国庫帰属で境界不明として却下されたのは申請約6,000件中23件）。要るときも、空中写真などから
  境界の案を作り、隣の所有者と合意して決める道がある（林野庁 §1-4）。重さと遭遇率を混同していた
- **使わせている約束** … 許可を得た貸し借りは農業委員会の台帳にある。許可の無い口約束は相続人を縛らず、
  亡くなった後に相続人が農業委員会を通した貸し借りに切り替えられる。取り返しはつく。
  時効取得の心配（§1-8）は、亡くなった後に早く整理する理由として、そのとき側に置く
- 初版で④に書いた「記録証明に出ない土地を見つける唯一の手がかり」、⑤の「戸建て以上に効く」は言い過ぎ。
  前の代の名義でも証明書は請求できる（§1-8）

**初版のときから落としていたもの**

- 国庫帰属を父が自分で申請しておく … 相続人も申請できる
- 森林経営管理制度の意向調査に答えたか … 回答は市町村に残る
- 森林組合・管理を頼んでいる先との約束 … 相手が記録を持つ。下の「契約」の材料
- 筆ごとの面積・地目の内訳 … 登記・名寄帳・台帳で取れる
- 団信 … 建物の無い土地のローンはまれ。ローンが記録されたときだけ立つ（既存の条件のまま）

★今のうち（行為）としては、マンションと同じく固有のものは立たない。**ただし落とした2つは、
記録としては持つ**（§2-0）。場所は所在として、使わせている約束は使っている相手として、下の部屋が持つ。
「台帳で辿れる」は今のうちから外す理由であって、記録から外す理由ではない。

### 2-4. 部屋ごとの整理（2026-10-01）

部屋は戸建て・マンションと同じ（基本情報／今のうち／そのとき／名義／契約／書類のありか）。
ローンは記録があるときだけ出す。前の版の 2-4〜2-6（そのとき・下の部屋・登録フォーム）はここへまとめた。

#### 基本情報（登録フォーム）

| 問い | 選択肢 | 何が決まるか |
|---|---|---|
| どんな土地か（今の使われ方で） | 田・畑／山林／家の建っていない宅地（空き地・駐車場）／人の家が建っている／その他 | 農地・森林の届出、宅地の境界・私道。農地法は登記の地目でなく現況で決まるので「今」で聞く |
| 呼び名 | 自由記入（「長野の田んぼ」「裏山」） | |
| どこにあるか | 市町村・地名（地番は分かれば） | 届出・申告の相手。家族が土地を探す起点（§2-0 の1行目） |
| 誰が使っているか | 父と母／父だけ／母だけ／子など、ほかの家族／家族以外の人／誰も使っていない（住んでいる人と同じ分け方。2026-10-01 に「父（と母）」から分けた） | 契約の部屋の「貸している」、そのときの「使っている人との関係」。「要らないとき」は誰も使っていないときと、**父だけが使っているとき**（父が亡くなると誰も使わなくなる） |

建てた年・部屋番号は出さない。

#### 今のうち（父の判断・署名が要る行為）

| 立つ条件 | 項目 | 父がすること |
|---|---|---|
| 常に | 前の代の名義 | 前の代の遺産分割に加わり、名義を決める（既存のフォーム。協議書ができているが登記していない、も既存の答えで受ける）。まとまりの**一部の筆だけ**前の代、がありうる |
| 常に | 登記の住所 | 違えば変更登記か、検索用情報の申出（マンションと同じ） |
| 宅地 | 境界と隣との取り決め | 戸建てと同じ |
| 宅地で、私道・通行・配管がある | 私道・通行・配管の取り決め | 戸建てと同じ |

#### そのとき（期限の早い順）

| 立つ条件 | カード | 期限 | 表に出すこと |
|---|---|---|---|
| 山林 | 森林の届出（市町村） | 90日 | 分割がまとまる前でも、相続人の共有で出す |
| 常に | 現所有者の申告（市町村） | 3か月 | 戸建てと同じ |
| 誰も使っていない・父だけが使っている | 要らないとき | 放棄の判断は3か月 | 土地だけは放棄できない／国が引き取る制度（条件・負担金）／隣の人が引き取ることがある |
| 田畑で、土地改良区の地区の中（か分からない） | 土地改良区 | ― | 意思にかかわらず組合員の資格を引き継ぐ／分割のあと資格の得喪を通知する（出さないと父の名義で賦課金が届き続ける）／賦課金の払い方を変える |
| 田畑 | 農地の届出（農業委員会） | 10か月 | 届出のとき、貸したい・売りたいの相談もできる |
| 貸している | 使っている人との関係 | ― | 契約の部屋の答えで分ける：農業委員会を通した貸し借りは続き、解約に許可が要る／口約束は相続人を縛らないが、賃料を受け取り続けると賃借権を時効で主張されうるので、早めに正式な貸し借りに切り替えるか返してもらう／無償なら父の死では終わらない／底地は借地の地主の立場を継ぐ |
| 常に | 相続登記（法務局） | 3年 | 前の代の名義があればそこから。地番は、所在の記録を手がかりに記録証明（前の代の名義でも請求できる）・名寄帳・農地ナビ・林地台帳で確かめる。評価額100万円以下の土地は登録免許税が免税 |

★「頼んでいる先（管理）」はそのときのカードにしない。相手と連絡先が契約の部屋にあれば、知らせるのは
気づけば誰でもできる（戸建ての「管理委託の引継ぎ」と同じ判定）。家族が困るのは**相手を知らないこと**
なので、記録（契約の部屋）が受け持つ。

#### 名義

| 持つもの | 中身 |
|---|---|
| 持ち方 | 単独／共有（持分） |
| 名義人 | 父／前の代（誰か）。前の代の中身は今のうちのフォームが持つ |
| 登記の住所 | 今の住所と同じか（今のうちのフォームで答える） |

区画は土地1つ（`rightKeys('land')` は実装済み）。

#### 契約（使っている人・頼んでいる先）

| 関係 | 例 | 持つもの |
|---|---|---|
| 貸している | 田畑を耕してもらっている／駐車場として貸している／人の家が建っている（底地）／農地バンクに貸している | 相手・連絡先・賃料を受け取っているか無償か・**農業委員会を通したか（田畑だけ：通した／口約束／分からない）**・書面の有無 |
| 管理を頼んでいる | 森林組合／草刈りを頼んでいる近所の人・親族／駐車場の管理会社 | 相手・連絡先・何を頼んでいるか |

「借りている（地主）」は土地では出さない（父が地主から借りている建物の無い土地は、父の土地ではない）。
父に聞かないと埋まらない部屋（§2-0）。

#### 書類のありか

| 書類 | 出るとき | 何に要るか |
|---|---|---|
| 権利証・登記識別情報 | 常に | 売るとき（相続登記には要らない） |
| 受け継いだとき・買ったときの書類 | 常に | 前の代の遺産分割協議書・売買契約書。前の代の名義が残っているとき、協議書があれば分割をやり直さずに済む |
| 賃貸借・借地の契約書、農業委員会の許可書・農地バンクの契約 | 貸していて書面があるとき | 相続人が貸主の立場を継ぐとき・解約するとき |
| 管理の契約書 | 管理を頼んでいて書面があるとき | 続けるか決めるとき |
| 境界・測量、越境の合意／私道の取り決め | 宅地で、今のうちの答えがあるとき | 戸建てと同じ |

建築・図面の資料は出さない（建物が無い）。

#### ローン

建物の無い土地への借入はまれ。記録があるときだけ部屋を出す（既存の条件のまま）。

## 3. 器（形）―― 公図の写し（2026-10-01）

更地を家の形で描かない（カテゴリー検討 §2）。主役と材料の部屋は戸建て・マンションと同じなので、
**器だけを土地の実物にする**。

### 3-1. なぜ公図か

| 候補 | 採らない理由／採る理由 |
|---|---|
| 田んぼの区画（真上から） | 田畑にしか見えない。山林・宅地で嘘になる |
| 山の等高線 | 山林にしか見えない |
| 境界杭・標柱 | 一点の物で、部屋を収める面を持たない |
| 登記事項証明書・名寄帳 | 文字の表。部屋が箇条の列になり、間取りと並べたとき「物」が無い |
| **公図（法務局の地図）** | **田畑・山林・宅地のどれにも共通する紙**。家族が地番を確かめるときに手にする。真上から見た地割りなので、間取りと同じく「面を部屋に割る」ことができる |

### 3-2. 公図をどこに描くか ―― 見出しの帯に収め、本体は中身に渡す（2026-10-01 改め）

初めの案は本体を公図にし、請求部分（父の土地）を真ん中に置いて周りに隣の筆を巡らせた。
**中身とぶつかる**：部屋はそのときのカードで幅も高さも使い切る。周りの筆を一周させればその分だけ
中身の幅が削られ、斜めの筆界は部屋の角に文字の入らない三角を作る。759px以下の1列では成り立たない
（造形が中身を収める、に反する）。

戸建て・マンションも、器の「らしさ」は見出し（屋根の帯／上の階）が持ち、本体は中身に従う間取り。
土地も同じ分担にする。

- **見出し＝公図の帯**：横幅いっぱい、高さは屋根の帯と同程度で固定。地割りは登記所備付地図データから切り出す。
  ★v38 で決めたこと（2026-10-01）：土地の種類によらず**同じ1本**（田畑の地割り）。帯は家族の土地の地図ではなく
  「公図という紙」の記号で、種類で絵を変えると「うちの土地の形」と読ませる方へ寄る（種類は札の字が言う）。
  ★父の土地として筆を**塗らない**。どの筆が父の土地かは分からないので、塗るとありもしないことを言う。
  札に隠れないよう横へずらした版は、1倍で意味の分からない四角が1つ残った（ユーザー指摘）
  呼び名・所在・どんな土地か・使っている人の札は、戸建てと同じトレペの札として帯に重ねる。
  地番は書かない（本物の写しに見せかけない）。方位の矢印は帯の隅
- **本体＝公図の紙面**：部屋（今のうち・そのとき・名義・契約・書類）が全幅を使う。仕切りは壁の厚みの無い
  細い線、通路は道の帯。線はまっすぐのまま（部屋の大きさは中身の実測で決める）

★残る心配：本体が「線の細い間取り」に見えること。見本で、戸建てと1倍で並べて確かめる。

### 3-2b. 本体に道・水路は描かない（2026-10-01、v38 で2回外した）

- 真ん中に「道」を通した版 … 部屋どうしの関係を何も言わず、1倍では列の間の溝にしか見えなかった。幅と仕切りの形だけを払っていた
- 外周の外（紙の下の余白）に「水路　○○土地改良区の地区」の帯を描いた版 … そのときの土地改良区のカードの言い直しで、
  家族が新しく知ることが無い。紙面のいちばん下（カードから約2,000px下）で、読まれない場所にあった

★「中身に対応するものがある」は描く理由にならない。描いたものが、その場で家族に新しいことを伝えるかで決める
（図は答えの言い直しにしない）。土地改良区の項目そのものは、帯と関係なく事実から立つので残す（§1-7b・§2-4）。

### 3-3. 自作か素材か（CLAUDE.md の判定）

- 方位・本体の仕切り … 線と矩形と文字 → 自作
- **見出しの帯の地割り** … 不規則な多角形の「それらしさ」が要る。勘で描くと人体ループに入る。
  **法務省の登記所備付地図データ（G空間情報センター、XML）を素材にする**。誰でも加工・商用利用でき、
  出典の表示と「加工した」旨の明記が条件（利用規約）。田畑・山林・宅地で地割りの手つきが違うので、
  種類ごとに実在の地区から1つずつ切り出す案がある。使ったら `body-front.README.md` と同じ形で
  出どころ・ライセンス・選んだ理由を残す
- 部屋の筆界は中身の実測で決める（間取りと同じ：位置＝優先、大きさ＝量、形＝公図）。
  今のうちを左上、そのときを主、材料を今のうちの下に置くのは戸建て・マンションと同じ並び

### 3-4. 次

`_検討/不動産v38.html` に見本を作る。仮データは「長野の田んぼ」（田畑・近所の人が口約束で耕作・
一部が前の代の名義）と「裏山」（山林・誰も使っていない）の2件。1倍で戸建ての間取りと並べて見る。
