# 土地（建物の無い土地）をどこで持つか ―― カテゴリー検討

2026-09-30。「物件を登録」フォームの種別を決める途中で、土地を戸建て・マンションと
同じ「物件」の延長で持つか、カテゴリーを分けるかが検討されていなかった。

分け方の基準は全体設計 §13：**別の情報構造・制度・判断を持つものは別の領域にする**。
あわせて §8（二度書きさせない）と §13-1「情報は親のところに置く」を当てる。

### 建物の無い土地で起きること（戸建て・マンションには無いもの）

| 事柄 | 中身 | 出どころ |
|---|---|---|
| 持っていることを知らない | 山林は評価額が低く、固定資産税の通知が来ないことがある。通知に載るのは課税対象だけ | 税理士法人の解説・東京相続の解説（下の出典） |
| 見つけ方 | 所有不動産記録証明制度（2026年2月2日〜）で、父の名義の不動産を全国一括で一覧にできる。名寄帳は市町村ごと | 法務省・旭川地方法務局 |

| 農地の届出 | 相続で農地を取得したら、知った時から**10か月以内**に農業委員会へ（農地法3条の3） | 農水省・各市町村 |
| 森林の届出 | 相続で森林の土地を取得したら、**90日以内**に市町村長へ。分割前でも法定相続人の共有として届け出る（森林法） | 林野庁・各県 |

## 2. 判定

### 分けない理由 ―― 手続きの相手と制度が同じ

- **相続登記・前の代の名義・現所有者の申告・名寄帳・所有不動産記録証明は、家も土地も
  同じ手続き**（法務局・市町村の固定資産税）。カテゴリーを分けると、同じ証明書・同じ
  申請が2か所に割れる（§8）
- 預金も遺産分割協議に入るのに銀行口座は別の領域になっている。それは**相手と制度
  （銀行）が違う**から。土地は、相手（法務局・市町村）が家と同じで、そこに農業委員会・
  林務が**加わる**だけ。§13 の「別の制度」には当たらない
- **家に付く田畑は家のところに置く**（§13-1 親のところに置く）。国交省の調査も
  「宅地と連接している田畑は居住している土地に含める」として数えている
- 「そのとき」で家族が見つけられないのは、**前の代の名義のままの土地**。これは戸建ての
  「前の代の相続登記」と同じ問い

### それでも「物件」の延長にはしない理由 ―― 形が違う

| | 戸建て・マンション | 建物の無い土地（田畑・山林など） |
|---|---|---|
| 1件の単位 | 1つの物件を深く記録する | 筆がいくつもあり、1筆ずつは浅い |
| 住まい | 誰が住むか・空き家・鍵 | 無い |
| ローン・建物の変更 | ある | ほぼ無い |
| 家族が決めること | 誰が住み続けるか・誰が継ぐか | 持つか・貸すか・手放すか |
| 今のうちに要ること | 境界・私道・増築・前の代 | どこにあるか・前の代の名義か・誰に耕作や管理を頼んでいるか |
| 期限のある届出 | 相続登記（3年） | ＋農地10か月・森林90日 |

1物件に1つの間取りを割り当てる今の形に入れると、住まい・ローン・建物の変更の部屋が
空のまま、更地が家の形で描かれる。

### 結論

**カテゴリーは分けない。建物の無い土地は、不動産・住まいの中に、物件（間取り）とは別の
形で持つ。** 家に付く田畑はその家の物件に入れる。

## 3. まだ確かめていないこと

→ 2026-10-01 `土地_調査と項目.md` で受けた（筆数は数字が見つからず、1件＝1か所のまとまりにして
依存しない形にした／宅地は土地の側／今のうち・そのとき）。

- 1つの家が持つ建物の無い土地は、ふつう何筆くらいか（「いくつもある」は調査の数字では
  まだ裏づけていない）
- 宅地（更地・月極駐車場・貸している土地＝底地）は、物件側か土地の側か。境界・貸す関係の
  深さは戸建てに近い
- 建物の無い土地の「今のうち」「そのとき」に何を載せるか（次の調査。
  `マンション_調査と項目.md` と同じ手順）
