# _検討｜作りかけを置く場所

本番（`prototype/`）に入れる前に、造形と寸法を確かめるための HTML を置く。
ここのファイルは**成果物ではなく、検討の記録**。

## 版番号は1本

不動産は以前、`間取り骨格` `間取り中身入り` `今のうち案` の3系列が
**別々に番号を走らせていた**。その結果、

- `間取り中身入りv23`（最新）
- `今のうち案v27`（こちらも最新）

が同時に成り立ち、どちらが最新か分からなくなった。番号の大きいほうが
古い、ということも起きる。

**領域ごとに通し番号を1本にする。** 系列を分けない。
不動産は `不動産v28.html` が現在地で、次は `不動産v29.html`。

v28 の番号は、旧2系列の大きいほう（今のうち案v27）の次を取った。
番号を戻すと、過去のコミットメッセージやメモの参照が全部ずれるため。

## 消していい・消してはいけない

- 次の版を作ったら、**その親でなくなった版は消す**。並べて比べたいときは
  git で取り出す
- ただし**失敗の記録**（なぜその道を選ばなかったか）は残す。消すと同じ道を
  もう一度通る
- 外から参照されているものは、消す前に参照元を直す
  （`prototype/**/_次セッション指示*.md`、`prototype/assets/*.README.md`）
