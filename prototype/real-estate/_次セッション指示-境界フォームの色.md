# 次セッション｜境界・越境の取り決めフォーム：件と話題の見分け（色）を決める

**推奨モデル：Opus**（配色の設計。1色ずつ試す作業ではない）

**ブランチ**：`feat/medical-memo-band`

---

## このセッションでやること

**境界・越境の取り決めフォームで、件（① 左隣／② 右隣）と話題（相手・決めたこと・書面…）が
見分けられる配色を、一組として設計する。**

前セッション（2026-09-29）は、色を v1〜v7 まで7回出して、どれも通らなかった。
**始める前に、ユーザーから「この色の組み合わせは良い」という参考（スクショ・サイト）を
1つもらう。** 参考なしで案を出さない。

---

## 本番に入れたこと（覆さない）

`editor.js`（境界の組み立て）と `area.css`。形は今までの本番のまま（件＝帯つきの白い札、中は問いを縦に並べる）。

1. 節の見出し「取り決め」（legend）を消した ―― ダイアログの見出しと同じ言葉が並んだ
2. 追加の入口は、上の問い「隣と、境界や塀・越境について決めたことはありますか」の右端。
   文言は「**＋追加**」（読み上げ名は「隣との取り決めを追加」）。「ある」のときだけ出す。件の下の追加ボタンは消した
3. 上の問いの注記を置かない。問いと選択肢で答え方が決まる。家族でも確かめられる書類の話は、
   「父も覚えていない」の後の問いが受け持つ
4. 「当てはまるものをすべて」は、問いの見出しの横に小さく添える（決めたこと／どんな書類ですか ×2）
5. 件の目次（隣との取り決め 2件 …）は、上の問いの下（本文の中）に置き、スクロールしたら上端に貼り付く。
   目次から飛ぶと、貼り付いた目次の下に件の頭が出る

## 決まっていないこと

**件の頭（灰色の帯「① 左隣との取り決め」）が、建物の権利関係の札の帯（「名義」など）と同じ形で、
意味が違う（件／話題）。これをどうするか。**

ユーザーが見本で選んだのは **案B**：件を枠で囲み、枠の中を権利関係と同じ帯つきの白い札（話題）に分ける。
ここまでは合意。**枠の色が決まらない。**

### 試して外れたもの（見本は `_検討/境界フォーム_案v1〜v7.html`）

| 版 | 件の枠の地 | ユーザーの反応・何が悪かったか |
|---|---|---|
| v1 | #F4F2EA（帯と同色） | 「背景色がおかしい」。枠全体が大きな帯に見えた |
| v2 | 塗らない（背景と同色） | 「背景と個数ごとの背景の色が一緒」 |
| v3 | #ECE8DC（帯より濃い） | 「どう考えても見づらい」。帯が枠より明るく浮いて濁った |
| v4 | #F7F5EE（帯より明るい） | 「全然上がってない」。また帯とほぼ同じ |
| v5 | 緑 --gr-bg／--gr-bg2 | 「センスない」。選択中の緑と同じ色相で、枠全体が「選んだ」色に見えた |
| v6 | 面の割り当て替え（床を塗る／件を白い札1枚に） | 「なんで同じ色相の中でしかやらないの？」「適切な色の組み合わせができない？」 |
| v7 | 青みの灰 #EDF1F6（OKLCH で L・C を帯にそろえ色相だけ離した） | 「同じ過ちを繰り返してる」 |

### 私（Claude）の癖 ―― 次は避ける

- **背景・帯の色を固定したまま、枠1枚の色だけを差し替え続けた。** 求められているのは
  背景・件・帯・選択の色を**一組として**設計すること（帯や背景を動かしてもよい）
- 薄い色（淡色）の中だけで動かした。色相を変えても、トーン（淡さ）が同じなら同じ失敗
- 色の指摘を「箱が3重だから構造の問題」と取り違え、構造の作り替えを2回言い出した ―― 却下された。
  **ユーザーが「色」と言ったら色の話だけをする**
- 1倍のスクショで「層が見分けられるか」しか見ず、「見て良い組み合わせか」を見ていなかった

### 次のやり方

1. ユーザーに参考をもらう（良いと思う配色の画面）
2. 参考から、背景・件・帯・選択・文字の組を取り出す（1色ではなく組で）
3. 案は2〜3組まで。手本（建物の権利関係）と並べ、1倍で見せる
4. 決まったら、本番の件（`.re-entry`）を案Bの形（枠＋中を話題の札）に組み替える。
   組み替えは色が決まってから（今の本番は件＝帯つきの白い札のまま）
