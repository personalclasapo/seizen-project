# 不動産「そのとき」の書面グリフ（v27）

「そのとき」の各手続きの頭に置く、A4 の書面を模したグリフ。
実体は `_検討/今のうち案v27.html` の `GLYPH`（インライン SVG）。

## 何の絵か

| キー | 何の書面か | 他と違うところ |
|---|---|---|
| `todoke` | 現所有者申告書（市町村へ出す） | 右上に**空の受理印枠**（角印・まだ出していない）＋下部に記入欄の囲み |
| `toki` | 登記識別情報通知（法務局から返ってくる） | 下半分の**目隠しシール**（斜線の帯。剥がすと12桁の符号）＋法務局の角印 |
| `tsushin` | 団信の請求一式（金融機関へ出す） | **3枚の綴り**（死亡診断書を含む一式）＋署名欄の手書き |
| `keiyaku` | 賃貸借契約書（引き継ぐ） | 甲乙2つの**丸印**が縦に並ぶ |

## なぜ自作か（CLAUDE.md の振り分け）

ケース1（幾何プリミティブ数個＋寸法を数個）に当たる。用紙は矩形、
罫は線、朱印は矩形と円。人体のような「それらしさに説得力が要るもの」
ではないので、PD/CC0 素材を探す前に自作してよい側。

寸法は実寸比から引いた：**A4 ＝ 210×297mm ＝ 1:1.414**。
viewBox は 30×42.4（30 × 1.414 ＝ 42.4）。勘で置いていない。

用紙そのものは `x:1.4→25.4 / y:1→37`。**印・シールはこの内側で閉じる**
（最初 `toki` の角印を x=17.2 w=6、`keiyaku` の丸印を cx=18.4 で置いて、
どちらも右へはみ出した）。

## 捨てた案：4種とも同じ「書面」

最初は共通の `sheetBase()`（折り角付きの用紙）に罫の本数だけ変えて
4種を作った。大きく出して並べたら**4枚とも同じ紙**で、「これは何の絵か」
に「書類」としか答えられなかった。CLAUDE.md「迷ったとき」に照らして破棄。

医療の先例（`medical-right-motifs.RESEARCH.md`）では、区別を**相手の実物**
で付けていた（病院＝建物／薬局＝乳鉢）。ここでも同じ筋を検討したが、
相手が 市町村・法務局・金融機関で**どれも建物**になり、同じ轍になる。
区別が付くのは**差し出す物のほう**だと判断して、上の4種に分けた。

## 30px では印が読めない → 主役は 54px にした（v27 第2版）

下の3案のうち **①を採った**。`sheet()` の第2引数に `w` を取り、
主役（相続登記）だけ 54px で出す。viewBox は変えていないので、
比率は A4 のまま。別プレート側は 30px のままで、そちらは輪郭と
綴りの有無だけが効いている。

以下は、その判断に至った記録。

## （記録）未解決だったこと：30px では印が読めない

大きく出せば4種は判別できるが、**実装サイズ（30×42.4px）では
朱印・目隠しシールの内側の線が潰れて、色の染みにしか見えない**。
用紙の輪郭と綴りの有無（`tsushin` だけ3枚）は 30px でも効いている。

座標を詰める作業を2回やった時点で手を止めた（CLAUDE.md §2）。
次にやるなら選択肢は3つ：

1. **グリフを大きくする**（40〜48px）。右ペインは 4:6 で幅に余裕が
   できたので、置ける
2. **印を落とす**。30px で効いている要素（輪郭・綴り・目隠しの帯）
   だけ残し、内側の線を消す
3. **素材を探す**。ただし「登記識別情報通知」のような日本固有の
   書式は PD/CC0 素材が見込み薄い

**1 か 2 が筋**。3 は当たっていない（当たるなら記録をここへ足すこと）。
