# 介護イメージ.png — 介護領域「連絡ボード」の造形の正本

介護の成果物UI（連絡ボード）の造形の正本。文章の指示よりこの画像が
優先。着手前に必ず開いて見る。医療の `医療.png` にあたるもの。

## 出どころ

ユーザーが生成した参考画像（2026-09-09 提示）。外部のPD/CC0素材では
ない。造形の方向づけとして採用し、寸法・割り付けはここから引く。

## この画像を正本とする範囲

**介護ゾーンだけ**。正本 §13 のとおり、ここで決めた形・寸法・規律を
他領域（医療ゾーン＝手帳／銀行／保険）へ持ち出さない。逆に、医療右面で
決めた造形（塗り→白チップへの置き換えなど）も、機械的にここへ
持ち込まない。個別に判断する。

## 造形（画像から読み取る要点）

### 器 ── 木枠のコルクボード

CLAUDE.md の iPhone フレーム相当の密度で SVG を層として組む。
`div` ＋ `border-radius` ＋ `linear-gradient` で代用しない。

- **木の額縁**：明るいオーク材。外周に見附（額の幅）を持ち、
  内側にもう一段細い枠（面取り）。四隅に留め具（丸いダボ）。
  見附の幅は額装の実比から引く（勘で置かない）。
- **背板**：木枠の内側は、ごく薄い木肌／リネン地のような一様な下地。
  コルクの粒立ちまでは描かない（乳白プレートを貼る面）。
- **プレート**：乳白〜生成りの半透明樹脂板。角丸。上2隅に真鍮の
  丸ネジ（横長のものは要所に複数）。プレートに落ち影。

### 節内の見出し

画像は「塗り面アイコン（角丸の色地）＋タイトル」だが、
**白地の角丸チップ＋細い緑枠＋緑の線グリフ**に変更した

ユーザー指示（2026-09-09）。外殻の一貫性を優先。

### サービス表

- 4列：サービスの種類／事業所／利用状況／連絡先
- 行頭アイコンは **塗り面**（画像どおり）。種類ごとに色を変え、
  「4種類のサービスがある」が一目で分かるようにする
  （訪問＝桃、通い＝青、配食／食事＝緑、生活支援＝紫 など）。
  ※節見出しの緑線グリフとは別物。行頭は色で見分けるのが役割
- 種類セルは主名＋補足（例：訪問介護／ホームヘルプ）

### 荷札（書類やもの）

- 下段プレートの中に、荷札（タグ）状の小片を横並び
- 各札：ものの名前＋所在（ピンアイコン＋場所）
- 穴＋紐通しの表現で「札」に見せる

## 画像から落としたもの（2026-09-09、ユーザー判断）

### 見出しプレート・キャッチコピー

- 「介護の連絡ボード」＋「いつものくらしを、みんなで支える」の
  見出しプレート → 削除
- 右上「安心できる毎日を、これからも」＋葉 → 削除
- 各節の一言（「困ったときはまずこちらへ」「いつもの支援で、安心の
  毎日を」「いざというときに、すぐに見つかるように」）→ 削除
- ケアマネの付箋・「家族が知っておきたいこと」の付箋 → 削除

素っ気なくする。連絡ボードは記録物であって、励ましのボードではない。

### 現在の生活場所（`place` / `placeNote`）

自宅か施設かの1情報はケアマネ経由でも家族の現況把握でも分かる。
住まいの様子（築年数・階段など）は日〜月で変わるうえ、同居・近居の
家族が口で言えるもの。§13-1「継続更新しないと古い記述が『確認済み』の
顔で残る」に該当。医療左面「普段の状態」を撤去したのと同じ理由。

### 家族が知っておきたいこと（`notes`）

「一人での入浴は見守りが必要」等。同居・近居の家族が既に知っている／
日々変わる。医療左面「普段の状態」撤去と同じ。基準線としての価値は
残るが、それは同席する家族が言えるもの。

### 週の予定の帯（`weekBlock` / `hasSchedule` / `weekGrid`）

サービスを表にしたので、利用状況の列で足りる。曜日の帯は別造形の
重複。放射図（本人を中心に左右へ振る図・矢印）も表に一本化。

### マスク・衛生用品などの消耗品（荷札から）

日々消費して所在も変わる。§13-1「継続更新しなければ正しくならない
こと」。荷札に載せるのは比較的安定した書類・もの（介護保険証・
負担割合証・お薬手帳など）の所在。

## 項目の詳細は一例

画像の項目名・seed の中身（要介護2、○○ケアサービス、介護保険証…）は
あくまで一例。構造が正本で、中身は差し替えてよい。荷札に何を載せるかも
「その家にある、比較的安定した書類・もの」の範囲で家庭ごとに変わる。

## §13-1 の所在の扱い

荷札は「ものの名前＋所在」だけを持つ。中身（保険証の番号など）は
持たない。所在が分かれば現物へ辿れる。「介護関係書類やもの」という
節名にしたのは、制度側の固定カテゴリを並べて埋めさせる形
（医療右面から撤去したもの）と区別するため ── その家に実際にある
ものの所在の棚であって、カテゴリ一覧ではない。

## 実装状況（2026-09-09）

参考画像に沿って介護ゾーンを作り替えた。file:// で 1400 / 1000 /
780 / 620 幅を確認。横スクロール・JSエラーなし。

- **器**：`careBoardFrame()` を木の額縁へ。木地（`.cbf-wood`）＋隅の
  合口の線（`.cbf-miters`、45°を4本）＋面取り（`.cbf-bevel`）＋
  背板（`.cbf-board`、内影つき）＋四隅の真鍮ダボ（`.cbf-peg`、CSS で
  真円）。1枚の SVG を引き伸ばすとダボが楕円化するので、桟は
  `--rail`（ボード幅の 4.4%）で固定、隅とダボは別レイヤー。
- **プレート**：`.cp`（乳白の半透明板＋落ち影＋真鍮ネジ `.cp-screw`）。
  上段は `.cp-row` で介護認定（`.cp-level`）＋担当者（`.cp-manager`）
  の2枚組、その下に横長の支援表・書類。≤900 で `.cp-row` は縦積み。
- **見出し**：`headChip()`（白チップ＋緑線グリフ）。塗り面アイコンは
  やめた（ユーザー指示）。グリフは `CARE_LEVEL_IC` / `CARE_PERSON_IC` /
  `CARE_HEART_IC` / `CARE_DOC_IC`（面取り＋線の2層、医療右面と同密度）。
- **介護認定**：要介護度＋認定の有無の札（`.cl-card`）。押すと
  `care.level` のセレクトを開く。
- **担当者・相談先**：ラベル＋値の縦グリッド（`.cm-row`）＋メモ＋
  状態バッジ。付箋（`cm-sticky`）は撤去。
- **利用している介護・生活支援**：`servicesBlock()` を表へ
  （`.svtbl` / `.svr`：種類／事業所／利用状況／連絡先）。行頭は
  塗り面アイコン（`fillIc(SV_IC[kind])`）で色分け。放射図・週の帯・
  中心の本人・矢印・曜日トグルは全削除。container ≤560 で行をカード
  状に積み、`data-th` でラベルを出す。
- **介護関係の書類やもの**：`carePapersBlock()` を荷札（`.ctag`）の
  横並びへ。名前＋所在（ピン）＋状態バッジ。消耗品は seed から外した。
- **state.js**：`care.place` / `care.placeNote` / `care.notes` 削除。
  `SERVICE_KINDS` を home/out/meal/life/equip の5型に（色は行の
  見分け用）。`DAYS` / `PLACES` / `weekGrid` / `hasSchedule` /
  `toggleDay` / `linesToText` / `applyLines` 削除。`applyTags` の
  ヌルバイト（`.join('\0')`）を `.join(' ')` に修正。
- **render.js**：`careSection` / `serviceCard` / `weekBlock` /
  `knowBlock` / 旧 `careBoardFrame` 削除。`PERSON_IC` / `WARN_IC` /
  `LEVEL_IC` / `DOC_IC`（介護専用で未使用化）削除。`data-day`
  ハンドラ・`LINE_PATHS` 削除。

## 造形の作り直し（2026-09-09・第2回）

上の「実装状況」で作ったものは、参考画像と並べると**器が別物**だった。
額縁・プレート・荷札・行頭アイコンのいずれも `div` ＋ `border-radius`
＋ `linear-gradient` で、CLAUDE.md の「輪郭を CSS の矩形で代用しない」に
反していた。しかも「次に詰めるところ」に自分で
`svg-motif-source-first` と書きながら、やったのは px の微調整だった。

**器から作り直した。** 調査と実測は
`assets/care-board-motifs.RESEARCH.md` に分けて残す。

### 直したこと

- **額縁**：`.cbf-wood` / `.cbf-bevel` / `.cbf-board`（CSS の箱）を捨て、
  `careBoardFrame()` が**1枚の SVG** に背板・落ち影・4辺の桟・木目・
  45°の合口・面取りを層として重ねる。見附は**実測 2.9%**
  （従来 4.4% は過大）。木目は長手方向に走り、縦桟と横桟で向きが
  変わる（`woodRail()`）。明暗は実測 Δ78 に合わせた。
- **背板**：`#ece6d9`（ほぼ白）→ **実測 `#a06b3c`**。プレートの
  すき間で採った値。板が奥にあることが色で分かるようになった。
- **プレート**：純白 `#fdfdfa` → **実測 `#f0e7de`**（生成りの樹脂板）。
- **ネジ**：CSS の `radial-gradient` の点 → SVG（円＋ハイライト＋
  マイナスの切り込み）。切り込みの向きは1本ずつ変えてある。
- **荷札**：角丸矩形＋丸1つ → **1本の閉じたパス**（斜めの切り欠き＋
  右の角丸）＋真鍮のハトメ。※途中、頭と胴を別 SVG に分けたら
  輪郭の端が札の中で切れて斜め線が走った。1本のパスに戻して解決。
- **行頭アイコン**：配食を **Openclipart の CC0 素材**（フォーク・
  ナイフ）＋皿の円に差し替え（`care-cutlery.svg` /
  `care-cutlery.README.md`）。生活支援は**ほうき→バケツ**へ変更
  ―― 18px に耐える CC0 のほうきが無く、自前のベジェは人体ループに
  なるため（判断の記録は RESEARCH.md）。

### 確認したこと

file:// で 1400 / 1000 / 780 / 620 幅。横スクロールなし、JSエラーなし。
4つの行頭アイコンは実寸（18px）で「家・バス・皿とカトラリー・バケツ」と
言える。
