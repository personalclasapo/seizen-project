# prototype/real-estate/kozu.js ― 公図の帯の地割り

不動産・住まいで、種別が「土地」の物件の見出し（戸建ての屋根・マンションの上の階にあたる帯）に
描く公図の地割り。`render.js` の `kozuBand()` が、帯の中心に合わせて筆の多角形を線で描く。
検討は `_検討/不動産v38.html`、判断は `設計/不動産・住まい/土地_調査と項目.md` §3。

## 出どころ

法務省「登記所備付地図データ」（G空間情報センター）の、長野県東筑摩郡山形村の地図XML
（`20450-1004-2026.zip` の中の `20450-1004-11.xml`）。

出典：「登記所備付地図データ 東筑摩郡山形村」（法務省）
https://www.geospatial.jp/ckan/dataset/houmusyouchizu-2026-1-981 を加工して作成（2026年10月1日に利用）

**ライセンス：登記所備付地図データ利用規約**（政府標準利用規約 第2.0版に準拠）。複製・加工・
商用利用ができる。条件は、出典を記載すること、加工したら加工した旨を記載すること、加工した
ものを国が作ったように見せないこと。上の出典の行がその記載にあたる（`kozu.js` の頭にも同じものを置いた）。

## 加工したこと

- 筆の外周（`GM_Surface` の外側の輪）だけを取り出し、**地番は捨てた**。実在の土地の地番を
  画面に出さない（規約の禁止行為「特定の個人を識別する行為」にも近づけない）
- 座標（任意座標系、m）を 0.6m／px にし、帯の中心からの px で持つ。横 1,800px・縦 140px の範囲に
  かかる筆だけ（115筆）
- 図郭（地図の区画の枠）の矩形は除いた

## なぜ自前で描かないか

公図らしさは、短冊の幅のばらつき、道の二重線、斜めに入る道、角の取り方といった地割りの
手つきから来る。勘で多角形を置くと人体のときと同じループに入る（CLAUDE.md の振り分け1の No）。
誰でも加工して使える実物の地割りがあるので、それを使う。

## なぜこの範囲か

山形村の図郭を並べて見比べ、道が縦横と斜めに走り、田の短冊が道に沿って並ぶ範囲を選んだ
（帯の候補を5つ切り出して比べた）。

## 決めたこと（覆さない）

- **土地の種類によらず同じ1本。** 山林の地割り（同じ村の `20450-1004-1.xml`）も切り出したが外した。
  帯は家族の土地の地図ではなく「公図という紙」の記号で、種類で絵を変えると「うちの土地の形」と
  読ませる方へ寄る。山林の版は筆の間の大きな空白・ギザギザの筆界・札の字にかかる濃い線で質も落ちた
- **筆を塗らない。** どの筆が父の土地かは分からないので、塗るとありもしないことを言う。法務局の
  公図の写しも白黒
