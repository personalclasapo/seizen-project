# 不動産・下エリアの造形 ―― 自作/素材の振り分け（2026-09-22）

CLAUDE.md「着手前に判定する」に従い、下エリア4部屋の造形を
着手前に振り分ける。項目は `設計/不動産・住まい/下エリア_調査と項目.md` §7 で確定済み。

## 前提：下エリアは今「物の形」を持っていない

上段は造形を持っている ―― 切妻屋根の物件見出し、表札（板＋小口＋面取り＋影）、
手続きシート、状態ノードの印。
一方、下段4部屋は `roomHead`（22px の角丸＋アイコン ＋ h4）が4つ並ぶだけで、
**4部屋とも同じ手つき**。間取り図の中の部屋でありながら、
中身が「何の絵か」を言えない。

## 振り分け

### 1. 権利関係 → **登記事項証明書の紙**／自作可

土地と建物で**別々の紙**が発行される。これが造形の核心
（マンションは一体なので1枚）。

- 幾何プリミティブ：矩形（紙）＋ 横罫 ＋ 上辺の表題欄の区切り線
- 寸法の実寸比：**A4 縦 210×297mm ≒ 1:1.414**
- 紙が2枚、少し重なって置かれる（土地・建物）

→ **振り分け1（自作可）。** 矩形と直線で成立し、寸法は A4 比から引ける。

★注意：登記事項証明書の書式そのものを精密に再現しない。
「甲区・乙区」等の専門用語を画面に出すと一般ユーザー向けでなくなる
（項目設計 §2「法的な敷地権等まで一般ユーザーに入力させない」の精神）。
**紙が2枚ある**ことが伝わればよい。

### 2. 契約・やり取り → **相手ごとの札**／自作可

§7-2 は3ブロック（続いている関係／借入／担保）。
相手の名前が頭に立つ構造は現状の `.who` が既に正しい。

- 幾何プリミティブ：矩形 ＋ 左端の色帯（種類）＋ 綴じ穴
- 周期（毎月27日など）は**小さなカレンダー目盛り**で表せる

→ **振り分け1（自作可）。**

★ただし**銀行口座領域の通帳と造形を共有しない**（正本 §13）。
ここは通帳ではなく「契約の綴り」。

### 3. 事情 → **付箋・鉛筆書き**／自作可

§7-3 の核心は**書面になっていない口約束**。
だから**書類の造形にしてはいけない** ―― 正式な記録でないことが
形で分かる必要がある。

- 幾何プリミティブ：矩形 ＋ 下辺のめくれ（三角）＋ 影
- 付箋の実寸比：**正方形 75×75mm（1:1）** が標準サイズ
- 判定（A）と経緯（B）を層で分ける：判定＝印、経緯＝付箋

→ **振り分け1（自作可）。**

### 4. 関係書類 → **封筒**／自作可

§7-4 で持つのは**所在だけ**（権利証・取得時の資料）。
索引ではないので、行を並べる造形にしない。

- 幾何プリミティブ：矩形 ＋ 三角の折り返し（フラップ）
- 実寸比：**長形3号 120×235mm ≒ 1:1.958**（日本の定形封筒の標準）
- 中身が「ある／無い／分からない」を、封の開閉と厚みで表す

→ **振り分け1（自作可）。** CLAUDE.md が例示する「封筒の三角折り」に該当。

## 素材を探すべきもの ―― 現時点で無し

4つとも幾何プリミティブ数個で成立し、寸法は実物の実寸比から引ける。
人体シルエット（`body-front.svg`）のような
「それらしさに説得力が要る」対象は含まれない。

★**ただし着手後の判定は別。** CLAUDE.md の振り分け2 に従い、
**スクショを見て座標を1つずつ動かす作業を2回以上やったら手を止めて
素材探しに切り替える。** その時点でこの README に追記する。
