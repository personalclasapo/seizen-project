# tree-side.svg — 庭木のシルエット（横から）

不動産「境界・越境の取り決め」の断面図で、越境している木の枝を描くのに使う。

## 出どころ

Wikimedia Commons の
[Blue Silhouette - Tree.svg](https://commons.wikimedia.org/wiki/File:Blue_Silhouette_-_Tree.svg)
（作者 ben、Openclipart 由来、2018-12-09）。元ファイルをそのまま置いている。

**ライセンス：CC0（パブリックドメイン）。** 表示義務は無いが、出どころを辿れるようにここに残す。

## なぜこれを選んだか

- 樹冠のかたまり＋幹＋枝分かれ、という最小の要素で、**幅 60px 程度でも木に見える**
- パスが1本（3.6KB）で、色は render.js で上書きできる（元の紺は使わない）
- 同じ検索で見た他の候補は合わなかった（`不動産-境界の図.RESEARCH.md`）

## なぜ自前で描かないか

木の輪郭（樹冠の凹凸・幹から枝への分かれ）は、CLAUDE.md が「説得力が要るもの」とする
側で、座標を手で置いて詰める作業に向かない。境界の図は、自作の配置図を2回描き直して
「雑すぎる」「分かりづらい」と言われた後に素材探しへ切り替えた。

## 使い方

`render.js` の `TREE_D` に、このファイルの `d` をそのまま持っている（`boundarySection`
が同期で描くため fetch しない）。元の座標系は translate(0,-642.36218) 付きで、
パスの外接矩形は x 12.3〜397.7・y 647.4〜1047.4（高さ 400）。幹の根元の中央を
x≈205・y≈1047.36 として、`translate(tx 0) scale(k) translate(-205 -1047.36)` で
地面に立てる。高さは実寸 3.0m（庭木）。
