# 医療.png — 医療領域「手帳」の見開きモック（正本）

医療領域の成果物UI（手帳の見開き）の造形の正本。文章の指示より
このモックが優先。1226×1283、手帳を開いた状態の全体像。

## 左ページ（本人そのもの）

- 表紙の題「医療の記録」＋一言。右上に葉のモチーフ
- 識別欄：写真枠（未登録は人型）＋本人名（大）＋生年月日・年齢・血液型
- 「現在の医療状態」節：見出しは **脈波アイコン＋タイトル**。
  治療中の病気を横並び（病名アイコン＋病名＋扱い）、「ほかの病気・
  状態も見る ＞」
- 「体に関わるもの」節：人体シルエットにピン＋リーダー線でカード
  （体内の機器＝塗り、続けている処置＝白抜き）。凡例を下に
- 「体に合わないもの」節：アレルギー・副作用歴を「原因 → 反応」で。
  右端にタグ（アレルギー／副作用）
- 「普段の状態」節：会話・認知・移動・食事を2×2の囲み

## 右ページ（場面）── ★今回の作業対象

3節すべて、見出しは **塗りアイコン（角丸の緑）＋タイトル＋一言**。

### いつもの通院

- 造形：**カードホルダー**。診療案内カードが半透明のポケットに
  数枚差さっている。前面のカードが全文、後ろのカードは上辺だけ覗く。
  カードの下端はポケットの裏に隠れる
- カード：診療科タグ（色地・角丸）＋病院名（太）＋主治医＋
  診療時間（複数行可）＋ TEL（右寄せ・太字）。カード地は淡い色
  （1枚目＝淡青、2枚目＝淡桃）。右端に建物の淡いイラスト
- ポケットの下に手書き風の一言「いつもの診療が、これからも安心して
  受けられるように。」＋葉

### 薬を確認するとき

- 一言「最新の薬の情報への入口です。」
- 上段：**実物タイル3つ横並び**。各タイルは
  - 実物のイラスト（お薬手帳＝紙の手帳／お薬手帳アプリ＝スマホ／
    マイナポータル＝PC画面）
  - 名前（太）＋補足（紙の手帳／スマートフォン／オンライン）
  - **確認済みバッジ**（緑・角丸）を下に
  - タイル地は淡い緑、角丸、枠線
- 下段：**かかりつけ薬局の帯**（1枚）。左に薬局アイコン＋
  「かかりつけ薬局」ラベル、右端に「＞」。薬局名（太）＋ TEL、
  下に一言「お薬の調剤・飲み合わせの確認をしてもらっています。」
- ※「その他」はタイルに出さない（編集時のみ）

### 医療で必要になるものと所在

- 一言「カードと書類の在りかです。」
- 造形：**カードホルダー**。色分けタブのカードが半透明ポケットに
  差さる（診察券＝青／マイナンバーカード＝桃／お薬手帳＝緑／
  各種医療手帳＝橙）。タブは色地・角丸で上辺から出る。カード名＋
  補足（「（3枚）」「（アプリ）」など）
- ポケット右上に**ゼムクリップ**が留まっている
- ポケットの下に手書き風の一言「いざというときに、すぐに取り出せる
  ようにしておきましょう。」＋葉

## §13 の整理

- 通院と「必要になるもの」は**どちらもカードホルダー系**で近い。
  区別は中身（診療案内カード vs 色タブのカード）と、通院側は
  診療科の色地・建物イラスト・診療時間という「案内」の情報で持つ。
  「必要になるもの」側のほうがカードホルダーとして素直
- 薬の節はカードホルダーにしない（実物タイル＋帯）ことで、
  右面3節が「カードホルダー／タイル／カードホルダー」ではなく
  拍子が割れる
