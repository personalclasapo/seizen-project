# body-front.svg — 人体シルエット（正面）

医療領域「現在の医療状態」の体の処置マップで使う人体シルエット。

## 出どころ

Wikimedia Commons の
[Human silhouette gender neutral.svg](https://commons.wikimedia.org/wiki/File:Human_silhouette_gender_neutral.svg)
から、正面向きの1体ぶんのパスだけを取り出して viewBox を 0 0 151.02 321.46 に
正規化したもの。

**ライセンス：パブリックドメイン（CC0）。** 表示義務は無いが、出どころを
辿れるようにここに残す。

## なぜ自前で描かないか

この造形は自前のベジェ曲線では作れなかった。関節（肩・肘・手・膝・足首）
のある人体の輪郭は、座標を手で置いて詰める作業に向いていない――何度書き
直しても、腕が胴に飲まれる／脚が棒になる／頭が離れる、といった破綻が残った。

CLAUDE.md の「成果物UIのモチーフは SVG で描く」は、**角丸の矩形で代用するな**
＝対象に見える造形を出せ、という要求。既製のパブリックドメイン素材を使うのは
その要求に反しない（むしろ、自前で描いて破綻させるほうが反する）。

ピン・リーダー線・ラベルカードは従来どおり `render.js` が描いて、この
シルエットの上に重ねる。

## 使い方

`render.js` の `bodyMap()` が fetch してインライン展開し、`.bmap-body` の
`fill` で色を当てる（元データの黒はここで上書きする）。部位のアンカー座標は
`state.js` の `BODY_REGIONS` が、この viewBox の座標系で持つ。
