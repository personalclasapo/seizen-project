### 1. 医療タイルの「層の作り方」を規則として抜き出す

**正本は `render.js` の `MEDSRC_ART`（1447行あたり）。** viewBox `0 0 64 48`。

医療が成立している理由は**数値ではなく層の構造**。ユーザー指摘：

> 「医療のアイコンをベースにするのに、数値だけの変化で再現できるわけ
> ないよね？」

読み取れている範囲（次セッションで精査すること）：

- **お薬手帳**＝表紙／**背から覗く中身の紙**（`M14 13c-2 .4-3.3 1.7...`）
  ／綴じ目／表紙の記号（円＋十字）／罫線 の**5層**。
  「中身が別の層として覗く」から冊子に見える。
- **マイナポータル**＝モニタの矩形／台座の台形／**画面の中に**人型と
  カード。**入れ子**になっている。
- 線幅 1.8（外形）/ 1.6（内部）/ 1.4（弱い要素・`#7ba98c`）は
  **層の遠近に対応**している。手前の外形が太い。
- 面は塗るが**淡色の地**（`#eaf3ec` / `#d7e8dc` / `#fff`）。線が主。

介護の色：線 `#b3823c`、淡い面 `#f6eddd` / `#eddcc0`（`.c-equip` の
`--sc` / `--sc-bg` 系）。

### 2. その規則で10種を組む

`EQUIP_TYPES`（state.js）の全項目に絵を用意し、**それ以外の自由入力は
`other`（受け皿）**に落とす。★`EQUIP_IC.other = EQUIP_IC.chair` は
**廃止する**（いま全部の「その他」が車椅子の絵になっている＝今回の指摘）。

| kind | 用具 |
|---|---|
| `bed` | 介護ベッド |
| `chair` | 車椅子 |
| `walker` | 歩行器 |
| `cane` | 杖 |
| `rail` | 手すり（工事なし） |
| `ramp` | スロープ |
| `bath` | 入浴補助用具 |
| `toilet` | ポータブルトイレ |
| `sensor` | 見守りセンサー |
| `other` | **その他＝自由入力の受け皿**（ラベル付きの箱など） |

※いまの state.js は `bed/walker/chair/cane/other` の5型。
上記に合わせて `EQUIP_KINDS` / `EQUIP_TYPES` を増やし、**移行（版6→7）**を
足すこと。★RESEARCH.md §3 の教訓：state.js の形を変えたら
`hydrate()`／`MIGRATIONS` を必ず見直す。

### 3. 自作でよい（ユーザー明言・2026-09-11）

> 「ちゃんと似せればいいだけで、決して自作がダメなわけでない。」

CLAUDE.md の「素材を探すのが先」は無条件の門ではない（判定基準は
出どころではなく**結果の質**）。**検出器だけは守る**――
「スクショを見て座標・px を1つずつ動かす作業を2回以上やったら手を止める」。
止まったら**同じ絵の別の描き方**（向きを変える等）へ。素材探しに
固定しない（第4回のベッドで通った教訓）。

## 素材の調査結果（済み・再探索は不要）

| セット | ライセンス | 画風 | 網羅 | 判定 |
|---|---|---|---|---|
| **Health Icons** | CC0 ✓ | **塗りシルエット**（医療と別系統） | ベッド・車椅子・杖のみ | **不採用**（画風） |
| **ICOOON MONO** | **再配布禁止 ✗** | 線画 ✓ | 豊富 | **不採用**（ライセンス） |
| **Tabler** | MIT ✓ | 線画だが**均一線のUI系**・層なし | ベッド・車椅子のみ | **不採用**（画風・網羅） |
| Openclipart | CC0 | — | **歩行器0件**（"walker"は犬の散歩人・綱渡り芸人・人名） | — |
| Material Symbols | Apache 2.0 ✗ | — | `assist_walker` は**杖をついた人**で歩行器ではない | **不採用** |

### ★ICOOON MONO を使えない理由（重要）

ライセンス本文：
> 「WEBサイトやCDなどで『ICOON MONO』に掲載している素材を再配布する
> ことは無料、有料を問わず禁止です。」

このプロジェクトは **SVG のパスを `render.js` に直接埋め込み**
（file:// で開くので fetch できない。`BODY_ART` と同じ事情）、**Git に入る**。
素材をソースに埋めて配布物に含めるのは再配布に当たる。直リンクも禁止
なので CDN 参照の逃げ道も無い。

**結論：どの既製セットも「医療タイルと同じ層の手つき」では出来ていない。**
医療タイルはこのプロジェクトのために描かれた「実物の絵」で、
汎用アイコンセットとは種類が違う。→ **自作する**。
